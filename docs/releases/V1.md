# Asterway V1 发布说明

本次按明确授权发布当前完整本地开发成果至 LingXI5499/asterway 的 feature/LingXI-develop 和 main，并使用用户指定的 V1 标签。保持全部技术依赖和现有工程版本；版本标签不改变 /asterway 接口前缀。

## 发布内容

账户 RBAC、JWT 与 Redis 会话；目标、阶段、任务、周／日计划；执行会话和连续时间段；习惯、分类、打卡与规则修订；目标达标站内提醒；今日看板、历史统计及状态时间线。前端共三十二页，本轮八个页面、七十三项交互及全局计时条均已实现，普通用户和管理身份的能力分开。

保留按业务模块维护的十份 SQL 和二十六表设计，不引入自动迁移、物理外键或业务模块间 Maven 依赖。

## 配置与隐私

- application.yml 随代码发布，数据库连接、用户名、密码，Redis 主机和密码，以及 JWT 密钥全部留空。
- 实际运行配置保存在未跟踪的私密目录，使用单份外部 YAML；没有引入环境变量或 profile。
- 移除历史连接检查脚本内的硬编码连接信息，改为读取指定私密 JSON。本地基础设施脚本从私密文件读取数据库密码，已有角色不改密码。
- 本地配置、凭据、工作记录、工程截图、依赖、构建输出、缓存及临时文件不进入发布快照。
- 提交与标签使用维护者 GitHub 账户及平台隐藏邮箱，不添加额外共同作者或工具署名。
