# Asterway V2.0

V2.0 完成成长助手第二阶段，将连续对话、业务查询、资料与记忆、规划确认、真实进度和复盘调整接入同一个成长工作区。

## 主要变化

- 统一全局成长助手入口、页面主题与导航层级，支持左右面板拖动调宽、宽度恢复和完整高度滚动。
- 持久化多会话、上下文摘要、流式回复、停止与失败恢复，并展示实际处理步骤。
- 提供 30 个只读业务工具，增加目标全貌查询、单轮结果复用和独立规划／复盘预算。
- 接入长期记忆、资料解析、pgvector 检索、文档不可变版本及引用回看。
- 在连续对话中自动澄清并生成方案，右侧展示目标、阶段、任务和计划；用户接受后由 Java 原子幂等提交。
- 跟踪目标、任务、计划和习惯的实际进度；依据执行统计生成复盘和可确认的调整方案。
- 支持跨周及已定日期之间改期，复用原任务并保留安排历史，版本冲突整批回滚。
- 完善方案执行重试、后台任务恢复、权限与数据归属校验，以及脱敏错误记录。
