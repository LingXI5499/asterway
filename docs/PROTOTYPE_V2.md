# v0.2 原型范围与需求讨论

这一阶段的结果是可交互前端，用来确认最终产品原型。未来约十万用户的目标属于后续服务端规划，本次没有做联网能力或并发容量承诺。

## 个人成长闭环

- 手动新建目标 → 新建多个关联任务 → 日程执行 → 习惯打卡 → 成长复盘。
- 27 个方向模板覆盖软考、考研、公考、CPA、法考、教资、四/六级、雅思、托福、JLPT、PMP；英语、日语、法语、西班牙语、英语阅读；Vue、Java、求职、写作、运动、作息、读书、减少刷手机、记账、绘画。
- 模板预览能设置开始日期和计划天数，一次建立目标、阶段、分布在周期内的任务和配套习惯。
- 伙伴对话独立于手动表单，能够新增计划、单独任务和习惯、记忆信息；批量操作有确认与保护后续修改的撤销。
- 个人知识库可手动编辑、收藏社区文字和接收伙伴记忆。已有每天学习分钟数可被伙伴计划规则引用。

## 参考布局的应用

| 参考内容类型 | 页面实现 |
| --- | --- |
| 图片、笔记、作品展示 | 社区图文瀑布流，高低错落；PC 2–4 列、手机双列 |
| 视频内容 | 竖向封面卡片 + 视频浏览弹窗，实际播放、循环、前后切换 |
| 计划或模板 | 阶段卡片网格，预览、复制到自己的成长目标 |
| 交流工作区 | PC 左侧会话列表 + 右侧聊天窗口，私信/群聊筛选 |
| 社群发现 | 卡片目录、成员示例、加入与群聊入口 |
| 数据与榜单 | 进度卡片 + 排名列表，突出本人真实行动数据 |
| 成长身份 | 段位阶梯、徽章网格、权益对比、用户主页 |
| 导航 | 三个分组、独立行、固定品牌和底部设置、内部滚动；手机抽屉 |

## 社区演示闭环

发布图文/视频/计划 → 点赞、评论、收藏 → 收入个人知识 → 复制计划 → 回到目标和任务。关注示例同行者，查看个人主页、发起私信；加入社群后进入群聊。

社区话题围绕考试、语言、职业技能、专注习惯、创作阅读，内容原则是分享真实过程、实用方法与友善鼓励。

## 成长游戏化

- 今日行动赛：当天完成 1 项任务与 1 次习惯打卡，领取 40 积分，每日期一次。
- 七日微习惯：加入后的七个不同日期打卡，领取 120 积分，一次；不要求连续。
- 专注挑战：加入后累计 25 分钟实际记录，领取 30 积分，一次。
- 六个段位按个人成长总分计算；八个徽章反映任务、习惯、复盘、专注、分享或挑战记录。
- 会员只演示身份和未来权益，价格待定，不触发付款，不限制现有功能。

## 后续原型讨论

1. 哪一类用户作为首批用户？默认首页应该偏学习、工作还是习惯？
2. 目标、阶段、任务的层级是否足够清楚？模板需要每天细排还是保留可调整空间？
3. 伙伴新增是否默认自动执行？哪些变更应始终确认？知识记忆怎样向用户展示？
4. 社区默认推荐图文、计划还是视频？社群要按人群还是成长方向组织？
5. 段位与排名是否造成压力？哪些积分行为值得奖励，怎样避免后续刷分？
6. 哪些会员权益真正有价值？先验证需求，再决定计费方案。

最终原型获认可后，再开发真实账号、服务端鉴权、数据库、媒体存储、实时通信、内容治理、AI/RAG、计费等。当前不预先堆叠这些架构。
