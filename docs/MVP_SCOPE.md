# Asterway v0.1.0 · 演示范围

## 本版目的

帮助合作伙伴建立对产品的基本认知，并讨论需求：**长期目标 → 今日行动 → 习惯积累 → 成长复盘 → 计划调整**。

依据外层的 GrowPilot 开发任务书实现，并按用户最新要求调整：正式品牌为 Asterway（星行纪）；使用 Vue 技术栈；项目根目录为 `Asterway`，前后端分别在 `asterway-web`、`asterway-server`；当前只开发前端。

## 已交付

- 中文 PC 工作台、移动端基础适配，七个页面和 404。
- 目标、里程碑、任务、习惯 CRUD 与关联；今日完成、XP 和进度联动。
- 周计划、任务池、手动改期、时段重叠提示；没有复杂拖拽。
- 习惯历史、周目标、每日习惯连续天数、有限补打。
- 7/30 天统计和每周复盘；所有指标从业务记录计算。
- 三类本地伙伴规则：精简今天、拆解目标、周摘要。修改前预览，明确确认，冲突保护撤销。
- localStorage 保存、演示数据、导入导出、重置和清空。
- 简单专注计时、搜索和快捷创建。

## 优先级与边界

演示闭环优先，方便修改需求优先。未建设复杂的数据平台或接口层。业务对象只服务于现有页面；伙伴有小型适配接口，便于后续替换。

后端目录只有说明文档。真实 AI、用户账户、云保存、跨设备同步、通知推送、深色模式、拖拽日历、社区、支付和原生 App 均未实现。

## 下一轮先讨论

1. 首个目标用户是谁，最常用的真实场景是什么？
2. 今日页是否应该只突出三件事？任务与习惯的划分是否清楚？
3. 用户最需要哪种计划调整，是否认可“预览后确认”的操作方式？
4. XP 是否能帮助用户理解成长，还是增加干扰？
5. 先调整哪些页面和字段，再决定账户、后端、AI 的真实接入需求。
