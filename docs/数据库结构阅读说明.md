# 数据库结构阅读说明

本说明只包含表结构、字段、约束和索引，不包含账号、对话、文档正文或其他用户记录。
业务 SQL 源文件位于 `backend/app/src/main/resources/sql/`；这些文件中的普通注释解释每条建表、筛选、初始化和授权语句。

## 共同规则

- `public` 保存账户和成长业务；`agent` 保存对话、记忆、知识资料、规划与复盘。
- 主键用于唯一定位一行；带 `user_id` 的业务记录必须核对当前用户归属。
- `NOT NULL` 表示必须有值；`DEFAULT` 是未传值时采用的内容；`CHECK` 拒绝不符合条件的行。
- 唯一约束阻止重复数据；索引主要用于加快指定条件的查找或排序。
- `version` 用于识别过时修改；时间点与用户业务日期是两种不同含义。
- 表之间没有物理外键；跨表归属、状态和原子写入由 Java/Python 业务事务校验。

## agent.background_task

文档解析/向量化等后台任务；仅记录调度与结果，不存业务事实

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| `id` | `bigint` | 是 | 本表记录编号，由数据库生成，用于唯一定位这一行 |
| `user_id` | `bigint` | 是 | 记录所属用户编号；读取和修改时必须核对当前登录用户 |
| `kind` | `character varying(32)` | 是 | 后台任务类型，用来选择文档解析、向量化、记忆抽取或复盘处理器 |
| `ref_type` | `character varying(32)` | 是 | 后台任务关联的对象种类，用来确定 ref_id 指向文档、记忆还是其他受控对象 |
| `ref_id` | `bigint` | 是 | 关联文档或记忆的逻辑引用，不建物理外键 |
| `status` | `character varying(16)` | 是 | 当前处理状态；允许值由本列对应的 CHECK 约束限制 |
| `attempts` | `integer` | 是 | 已尝试次数，最多 20 次，超过后由服务置为失败 |
| `error_code` | `character varying(64)` | 否 | 最近一次失败的稳定错误编码；页面和日志据此区分失败原因 |
| `error_message` | `character varying(1000)` | 否 | 供用户阅读的失败原因；不保存密钥、完整上游响应或内部堆栈 |
| `scheduled_at` | `timestamp(3) with time zone` | 是 | 允许后台任务被领取执行的最早时间点 |
| `started_at` | `timestamp(3) with time zone` | 否 | 本次处理实际开始的时间点；尚未开始时可以为空 |
| `finished_at` | `timestamp(3) with time zone` | 否 | 本次处理进入成功、失败或取消终态的时间点；进行中可以为空 |
| `version` | `bigint` | 是 | 乐观锁版本号；更新时递增，旧版本请求不能覆盖新结果 |
| `created_at` | `timestamp(3) with time zone` | 是 | 记录首次创建的时间点 |
| `updated_at` | `timestamp(3) with time zone` | 是 | 记录最后更新的时间点，由应用写入时维护 |

约束负责拒绝不合法或重复的数据：

- `background_task_attempts_check`：`CHECK (((attempts >= 0) AND (attempts <= 20)))`。
- `background_task_kind_check`：`CHECK (((kind)::text = ANY ((ARRAY['DOCUMENT_PARSE'::character varying, 'DOCUMENT_EMBEDDING'::character varying, 'MEMORY_EMBEDDING'::character varying, 'MEMORY_EXTRACT'::character varying, 'REVIEW_GENERATE'::character varying])::text[])))`。
- `background_task_pkey`：`PRIMARY KEY (id)`。
- `background_task_ref_id_check`：`CHECK ((ref_id > 0))`。
- `background_task_ref_type_check`：`CHECK (((ref_type)::text = ANY ((ARRAY['KNOWLEDGE_DOCUMENT'::character varying, 'MEMORY'::character varying, 'CONVERSATION_TURN'::character varying, 'REVIEW_REPORT'::character varying])::text[])))`。
- `background_task_status_check`：`CHECK (((status)::text = ANY ((ARRAY['PENDING'::character varying, 'RUNNING'::character varying, 'SUCCEEDED'::character varying, 'FAILED'::character varying, 'CANCELLED'::character varying])::text[])))`。
- `background_task_user_id_check`：`CHECK ((user_id > 0))`。
- `background_task_version_check`：`CHECK ((version >= 0))`。
- `ck_agent_background_task_ref`：`CHECK (((((kind)::text = ANY ((ARRAY['DOCUMENT_PARSE'::character varying, 'DOCUMENT_EMBEDDING'::character varying])::text[])) AND ((ref_type)::text = 'KNOWLEDGE_DOCUMENT'::text)) OR (((kind)::text = 'MEMORY_EMBEDDING'::text) AND ((ref_type)::text = 'MEMORY'::text)) OR (((kind)::text = 'MEMORY_EXTRACT'::text) AND ((ref_type)::text = 'CONVERSATION_TURN'::text)) OR (((kind)::text = 'REVIEW_GENERATE'::text) AND ((ref_type)::text = 'REVIEW_REPORT'::text))))`。
- `ck_agent_background_task_status`：`CHECK (((((status)::text = 'PENDING'::text) AND (started_at IS NULL) AND (finished_at IS NULL) AND (error_code IS NULL)) OR (((status)::text = 'RUNNING'::text) AND (started_at IS NOT NULL) AND (finished_at IS NULL)) OR (((status)::text = 'SUCCEEDED'::text) AND (started_at IS NOT NULL) AND (finished_at IS NOT NULL) AND (error_code IS NULL)) OR (((status)::text = 'FAILED'::text) AND (started_at IS NOT NULL) AND (finished_at IS NOT NULL) AND ((error_message)::text ~ '[^[:space:]]'::text)) OR (((status)::text = 'CANCELLED'::text) AND (finished_at IS NOT NULL))))`。
- `ck_agent_background_task_time`：`CHECK ((isfinite(created_at) AND isfinite(updated_at) AND (updated_at >= created_at) AND ((started_at IS NULL) OR (isfinite(started_at) AND ((started_at >= created_at) AND (started_at <= updated_at)))) AND ((finished_at IS NULL) OR (isfinite(finished_at) AND ((finished_at >= created_at) AND (finished_at <= updated_at))))))`。

索引定义了查找、排序或唯一性检查使用的字段：

- `background_task_pkey`：`CREATE UNIQUE INDEX background_task_pkey ON agent.background_task USING btree (id)`。
- `ix_agent_background_task_due`：`CREATE INDEX ix_agent_background_task_due ON agent.background_task USING btree (status, scheduled_at, id)`。
- `uk_agent_background_task_active`：`CREATE UNIQUE INDEX uk_agent_background_task_active ON agent.background_task USING btree (kind, ref_type, ref_id) WHERE ((status)::text = ANY ((ARRAY['PENDING'::character varying, 'RUNNING'::character varying])::text[]))`。

## agent.call_record

- `call_record_duration_ms_check`：`CHECK ((duration_ms >= 0))`。
- `call_record_first_token_ms_check`：`CHECK ((first_token_ms >= 0))`。
- `call_record_kind_check`：`CHECK (((kind)::text = ANY ((ARRAY['MODEL'::character varying, 'TOOL'::character varying, 'EMBEDDING'::character varying])::text[])))`。
- `call_record_pkey`：`PRIMARY KEY (id)`。
- `call_record_prompt_tokens_check`：`CHECK ((prompt_tokens >= 0))`。
- `call_record_status_check`：`CHECK (((status)::text = ANY ((ARRAY['SUCCEEDED'::character varying, 'FAILED'::character varying, 'CANCELLED'::character varying])::text[])))`。
- `call_record_user_id_check`：`CHECK ((user_id > 0))`。

索引定义了查找、排序或唯一性检查使用的字段：

- `ix_agent_call_owner_date`：`CREATE INDEX ix_agent_call_owner_date ON agent.call_record USING btree (user_id, created_at DESC, id DESC)`。

## agent.checkpoint_blobs

工作流检查点使用的通道值；较大的序列化内容单独保存，避免每次重复存储

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| `thread_id` | `text` | 是 | 工作流恢复使用的逻辑线程标识；由用户、运行和方案版本组成 |
| `checkpoint_ns` | `text` | 是 | 检查点的命名空间，用于隔离主流程与子流程 |
| `channel` | `text` | 是 | 检查点里某一类状态值的通道名称 |
| `version` | `text` | 是 | 乐观锁版本号；更新时递增，旧版本请求不能覆盖新结果 |
| `type` | `text` | 是 | 该段状态内容的序列化类型，恢复时按相同方式解码 |
| `blob` | `bytea` | 否 | 按 type 指定方式编码的原始字节内容，恢复时由工作流库解码 |

约束负责拒绝不合法或重复的数据：

- `checkpoint_blobs_pkey`：`PRIMARY KEY (thread_id, checkpoint_ns, channel, version)`。

索引定义了查找、排序或唯一性检查使用的字段：

- `checkpoint_blobs_pkey`：`CREATE UNIQUE INDEX checkpoint_blobs_pkey ON agent.checkpoint_blobs USING btree (thread_id, checkpoint_ns, channel, version)`。
- `checkpoint_blobs_thread_id_idx`：`CREATE INDEX checkpoint_blobs_thread_id_idx ON agent.checkpoint_blobs USING btree (thread_id)`。

| 字段 | 类型 | 必填 | 含义 |

## agent.conversation

Agent 会话；用户自有，关闭后只读，删除为逻辑删除，原始消息与摘要分开保留

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| `id` | `bigint` | 是 | 会话主键；对外按字符串传输 |
| `user_id` | `bigint` | 是 | Java 验证得到的所属用户，不从客户端请求体或模型参数读取 |
| `title` | `character varying(100)` | 是 | 可修改的会话标题，1～100 字，空白标题无效 |
| `status` | `character varying(16)` | 是 | 对话生命周期状态；历史关闭接口保留，当前界面主要使用活跃与删除流程 |
| `context_summary` | `text` | 是 | 派生历史摘要，最多 16000 字；不替代原始消息，不作为认证或业务授权依据 |
| `summary_through_message_no` | `bigint` | 是 | 摘要已覆盖的连续历史边界；Service 只在终态轮次边界推进，保留原始消息 |
| `summary_updated_at` | `timestamp(3) with time zone` | 否 | 摘要最后提交时间；无摘要时为空 |
| `next_message_no` | `bigint` | 是 | 分配下条会话内消息序号；事务内锁会话后递增，不用时间戳排序 |
| `last_message_at` | `timestamp(3) with time zone` | 否 | 最近消息写入时间；没有消息时为空 |
| `closed_at` | `timestamp(3) with time zone` | 否 | 关闭时间；ACTIVE 为空，CLOSED 必填，关闭后不再发起生成 |
| `deleted_at` | `timestamp(3) with time zone` | 否 | 逻辑删除时间；删除后所有接口按不存在处理，不清空历史事实 |
| `version` | `bigint` | 是 | 标题、关闭、删除、摘要及序号分配等会话更新的乐观锁版本 |
| `created_at` | `timestamp(3) with time zone` | 是 | 记录首次创建的时间点 |
| `updated_at` | `timestamp(3) with time zone` | 是 | 记录最后更新的时间点，由应用写入时维护 |

约束负责拒绝不合法或重复的数据：

- `ck_agent_conversation_status`：`CHECK ((((((status)::text = 'ACTIVE'::text) AND (closed_at IS NULL)) OR (((status)::text = 'CLOSED'::text) AND (closed_at IS NOT NULL))) AND ((deleted_at IS NULL) OR ((status)::text = 'CLOSED'::text))))`。
- `ck_agent_conversation_summary`：`CHECK (((summary_through_message_no < next_message_no) AND (((context_summary = ''::text) AND (summary_through_message_no = 0) AND (summary_updated_at IS NULL)) OR ((context_summary ~ '[^[:space:]]'::text) AND (summary_through_message_no > 0) AND (summary_updated_at IS NOT NULL)))))`。
- `ck_agent_conversation_time`：`CHECK ((isfinite(created_at) AND isfinite(updated_at) AND (updated_at >= created_at) AND ((last_message_at IS NULL) OR (isfinite(last_message_at) AND ((last_message_at >= created_at) AND (last_message_at <= updated_at)))) AND ((summary_updated_at IS NULL) OR (isfinite(summary_updated_at) AND ((summary_updated_at >= created_at) AND (summary_updated_at <= updated_at)))) AND ((closed_at IS NULL) OR (isfinite(closed_at) AND ((closed_at >= created_at) AND (closed_at <= updated_at)))) AND ((deleted_at IS NULL) OR (isfinite(deleted_at) AND ((deleted_at >= closed_at) AND (deleted_at <= updated_at))))))`。
- `conversation_context_summary_check`：`CHECK ((char_length(context_summary) <= 16000))`。
- `conversation_next_message_no_check`：`CHECK ((next_message_no > 0))`。
- `conversation_pkey`：`PRIMARY KEY (id)`。
- `conversation_status_check`：`CHECK (((status)::text = ANY ((ARRAY['ACTIVE'::character varying, 'CLOSED'::character varying])::text[])))`。
- `conversation_summary_through_message_no_check`：`CHECK ((summary_through_message_no >= 0))`。
- `conversation_title_check`：`CHECK (((title)::text ~ '[^[:space:]]'::text))`。
- `conversation_user_id_check`：`CHECK ((user_id > 0))`。
- `conversation_version_check`：`CHECK ((version >= 0))`。

索引定义了查找、排序或唯一性检查使用的字段：

- `conversation_pkey`：`CREATE UNIQUE INDEX conversation_pkey ON agent.conversation USING btree (id)`。
- `ix_agent_conversation_user_page`：`CREATE INDEX ix_agent_conversation_user_page ON agent.conversation USING btree (user_id, updated_at DESC, id DESC) WHERE (deleted_at IS NULL)`。
- `ix_agent_conversation_user_status`：`CREATE INDEX ix_agent_conversation_user_status ON agent.conversation USING btree (user_id, status, updated_at DESC, id DESC) WHERE (deleted_at IS NULL)`。

## agent.conversation_message

会话内顺序消息事实；保留用户、助手、工具结果和中断的部分文本，不保存系统密钥或客户端自报身份

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| `id` | `bigint` | 是 | 本表记录编号，由数据库生成，用于唯一定位这一行 |
| `user_id` | `bigint` | 是 | 记录所属用户编号；读取和修改时必须核对当前登录用户 |
| `conversation_id` | `bigint` | 是 | 所属对话编号，必须与当前用户的数据范围一致 |
| `turn_id` | `bigint` | 是 | 所属提问轮次逻辑标识；同会话同用户必须由 Service 核对，不伪装成行内 CHECK |
| `message_no` | `bigint` | 是 | 会话内严格递增序号；并发分配由会话行锁和 next_message_no 负责 |
| `role` | `character varying(16)` | 是 | 消息发送者种类，区分用户、助手和工具结果 |
| `content` | `text` | 是 | 用户最多 8000 字，助手和工具最多 65536 字；工具结果只保存业务允许返回的脱敏内容 |
| `is_complete` | `boolean` | 是 | 助手部分输出为 false；失败、取消、截断的文本可展示，但不能作为已确认回答进入后续推理 |
| `tool_calls` | `jsonb` | 是 | 助手原始工具调用数组，结构上限 32 项／256 KiB；实际注册白名单及更小预算由后续工具模块执行 |
| `tool_request_message_id` | `bigint` | 否 | 工具结果对应的助手消息逻辑标识；Service 核对同用户、同会话、同轮次及调用标识 |
| `tool_call_id` | `character varying(128)` | 否 | 对应助手 tool_calls 内的调用标识；不同助手消息允许使用相同调用标识 |

## public.task_state_history

任务状态和真实完成的追加式事实；只记实际变化，BASELINE 不计完成，历史不可由业务接口修改删除

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| `id` | `bigint` | 是 | 数据库生成的 BIGINT 标识，对外按字符串传输 |
| `user_id` | `bigint` | 是 | 所属用户，写入与查询均由服务端限定本人 |
| `task_id` | `bigint` | 是 | 所属业务对象逻辑标识；逻辑删除后保留引用 |
| `event_type` | `character varying(24)` | 是 | 真实业务事件类型；BASELINE 为上线时当前状态，COMPLETION_IMPORTED 仅用于导入可信任务完成时间 |

| `after_status` | `character varying(20)` | 是 | 变化后状态，使用当前业务对象既有枚举 |
| `name_snapshot` | `character varying(100)` | 是 | 该事件发生时的名称；不是整份业务资料快照 |
| `entity_version` | `bigint` | 是 | 该事件对应的主体版本，允许无状态变化的资料修改留下版本间隔 |
| `occurred_at` | `timestamp(3) with time zone` | 是 | 实际发生时间，或旧任务已知的 completed_at；基线采用初始化时间 |
| `source_type` | `character varying(24)` | 是 | 由服务端填写：用户动作、通知确认、执行开始或系统初始化 |
