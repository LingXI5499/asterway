## 一、系统设计目标

保持模块化单体，实现“目标→阶段→任务→本周/某日安排→可信执行→完成→历史回顾”闭环；习惯独立运行。采用单后端实例、同库事务与服务端可撤销会话。优先保证授权、日期归属、不可逆事实、失败可判断及恢复后权限正确。

### 2.2 本期不包含

沿用 01 的范围排除，不新增服务注册中心、分布式事务、消息中间件、业务缓存集群或向量检索依赖。服务器已有扩展不代表业务必须使用。

### 2.3 MVP 验收边界

普通用户可独立完成主链路、习惯和历史回顾；后台权限受限；双设备并发、断网恢复、时区跨日、重复请求及历史保留有证据。全部适用测试完成、关键缺陷关闭并通过隔离恢复演练后，才具备生产发布条件。

## 三、总体架构

### 3.1 架构图/文字结构

```text
PC 浏览器（Vue / TypeScript）
  → HTTPS → Nginx（静态资源、同域 /api 反向代理）
    → app（HTTP、安全、应用用例、调度及启动恢复）
      → 8 个业务工程（进程内调用）+ common
        → MyBatis XML → 远程 PostgreSQL 17.11
        → 独立安全账本 / 独立备份与 WAL 归档
```

应用网络只公开必要 HTTPS 和运维入口；数据库由远程主机管理，不随应用容器删除。当前仅后端骨架存在，Nginx、Compose、前端、数据库迁移、账本适配及监测尚未落地。

### 3.2 架构说明

| 层次 | 职责 | 输入 | 输出 | 依赖 |
|---|---|---|---|---|
| 浏览器 | 表单、导航、状态反馈 | 用户动作与服务端响应 | 契约请求与可见状态 | HTTP、有效会话 |
| app | 认证、授权、跨模块用例及事务协调 | HTTP DTO 和系统触发 | VO、错误、持久事实 | 业务模块与 common |
| 业务工程 | 各自规则与数据所有权 | 已核验业务上下文 | 业务结果 | common、Mapper XML |
| PostgreSQL | 主键、唯一、行内及排除约束 | 参数化 SQL | 持久事实和一致结果 | 迁移角色、btree_gist |
| 独立恢复设施 | 备份与撤销依据 | 基础备份、WAL、安全变化 | 可核验恢复链 | 独立存储和权限 |

## 五、技术选型与职责映射

| 技术 | 版本基线 | 位置 | 职责 | 理由 | 替代方案/不采用原因 |
|---|---|---|---|---|---|
| JDK | 17；本机 17.0.18 | 后端 | 统一编译与运行 | 现行 POM 已设置 release=17 | 不沿用旧 JDK 21 设计 |
| Maven | 3.9.4 | 聚合构建 | 父工程+10 子模块 | 既有工具及 wrapper properties | 不独立发布业务工程 |
| Spring Boot | 3.5.16 | app | Web/安全/事务/校验 | 现行父 POM | 不回退旧 4.x 设计 |
| MyBatis Starter | 3.0.5 | 持久化 | SQL 与结果映射均 XML | 已确定工程边界 | 不引入另一套业务 ORM |
| PostgreSQL | 17.11；运行实例待核验 | 远程库 | 数据与约束 | 现行环境记录 | 不采用旧 18.x 文档基线 |
| Flyway / Spring Session | 随 Boot BOM；以依赖树复核 | app | 迁移及可撤销会话 | 已声明依赖 | 会话表需无外键适配 |
| Vue / TypeScript | 3.5.44 / 6.0.3，设计记录 | 规划前端 | 交互与类型 | 现行版本册 | 尚无 package.json 和锁文件 |
| Node / npm | 24.22.0 / 11.19.1，设计记录 | 前端构建 | 可复现安装 | 现行版本册 | 本机 Node 24.15.0 与目标不同 |
| Nginx / Compose | 部署时锁定版本与镜像摘要 | 应用主机 | 同域入口与进程编排 | 现行部署设计 | 目前无可执行部署清单 |

### 5.1 技术职责边界

前端不持有授权和计时事实的最终判断权；后端从会话取身份，锁后重验父链、版本和资格；数据库落实唯一及时间不重叠等可表达约束。公共安全链路处理身份撤销、CSRF 和错误映射，业务服务处理状态。外部账本不能冒充同库原子事务。

### 5.2 技术选型约束

app 依赖 common 与八个业务工程；业务工程仅依赖 common，兄弟工程不互相依赖。outbox 采用同库持久记录并异步消费。业务 SQL 不写注解或 Provider。当前不建设物理外键、数据库级联或查询父表模拟外键的触发器。

## 六、关键架构约定

| 主题 | 现行约定 | 影响 |
|---|---|---|
| 交互 | /api/v1、JSON、UTC 时刻与业务日期分开 | long/版本/时长按十进制字符串 |
| 认证 | 服务端会话、Cookie、写请求 CSRF | 逐请求检查当前安全版本 |
| 数据访问 | 本人归属+父链+状态+版本 | 管理员个人接口也只读本人 |
| 事务 | READ COMMITTED、锁后重读、统一锁序 | 跨模块核心事实一次提交 |
| 重复请求 | Idempotency-Key 与原意图指纹 | 未知结果先核实；同键异参拒绝 |
| 响应 | code/message/data/traceId；声明可空字段显式 null | 当前 non_null 配置需在实现阶段修正 |
| 密钥 | 外置环境或受控秘密文件 | 文档和仓库不保存真实值 |
| 迁移 | app 的 db/migration；追加版本 | 当前尚无 SQL；框架表无外键 |
| 观测 | traceId、审计、事件水位与恢复点 | 不记录密码、会话或许可材料 |
