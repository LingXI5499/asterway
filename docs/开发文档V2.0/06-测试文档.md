# 06 测试文档

> 项目：Asterway · 个人成长管理
> 文档版本：V2.0　编制日期：2026-10-22　状态：设计审阅稿
> 工程基点：`f4aca730c81eddd9ba6a8598f4a0df2cbde02bed`；软件版本：`0.1.0-SNAPSHOT`。

> 测试构建：尚无业务测试构建。环境：设计期本地核对；测试责任角色：测试执行者与业务验收者，尚未指定具体个人。业务测试周期尚未开始；本次文档核对日期为 2026-10-21。

## 一、测试目标与范围

### 1.1 测试目标

验证 132 项功能、95 个接口、7 类系统处理、36 张表的完整性、20 个页面以及 84 项质量需求（含 4 项基础可访问性）。所有数字指设计范围，不代表运行通过。

### 1.2 测试范围

功能覆盖 01～04；接口覆盖 API 全集；非功能覆盖 NFR 全集。知识库、社区、协作和向量检索等本期范围外能力不测。测试设计已具备，业务执行尚未开始。

### 1.3 测试依据

01～08 采用 V2.0；业务和数据库字典继承V2.0 业务规则和设计册；工程基点和版本见 09。数据库迁移版本尚不存在。旧 TEST-001～072 保留原编号，增加 TC-001～072 作为同一用例别名，不重复统计。

## 二、测试类型与职责

| 类型 | 对象 | 重点 | 执行方式 | 证据 |
|---|---|---|---|---|
| 接口 | 单条 HTTP | 状态、字段、错误、权限、重复请求 | 真实 HTTP 自动化或调试记录 | 脱敏请求响应和 traceId |
| 单元 | 独立业务函数 | 日期、状态、公式、Unicode 边界 | 隔离依赖、固定时钟 | 输入与断言 |
| 集成 | Service/Mapper/数据库 | 锁、事务、排除、会话仓库 | 真实 PostgreSQL 隔离库 | 事务前后和并发时间线 |
| 前后端联调 | 浏览器到后端 | 字段、CSRF、会话和页面状态 | 真实前后端 | 页面证据对应服务端事实 |
| 系统 | 完整链路 | 双设备、恢复和质量 | 完整测试环境 | 端到端及故障报告 |
| 业务验收 | 场景与交付范围 | 使用者目标是否达成 | 业务角色按场景验收 | 明确接受或拒绝结论 |

## 三、测试环境与数据

后端 JDK 17/Boot 3.5.16，PostgreSQL 17.11 目标实例先核验，前端按锁文件记录实际版本；浏览器与 OS 版本在执行时登记。本机模型校验不使用业务数据库，也不证明数据库可连接。

建立普通用户 A/B、管理员、两个可用超级管理员的合成账号，凭据经安全渠道注入。准备未来目标、空目标、部分执行、完成/删除历史、周内无日期任务、跨午夜区间和各种习惯节点。日期固定可重放时钟，覆盖上海、纽约夏令时、周日到周一、年末和日期线重复日。

测试库可由版本化脚本重建；并发测试独立账号和实例，避免共享夹具污染。不得使用生产密码或原始个人正文。性能数据及参考资源见 02；正式测量记录网络、数据库资源、外部依赖、原始样本和失败数。
