## 附录与维护

附录保留完整字段、响应对象、接口示例、页面交互、系统处理、实施细则、技术基线、专项测试与需求追溯。正文由 tools 编排，字段、接口与业务输入集中在编制源文件。修改输入并复核后，先执行 `python -X utf8 docs/开发文档V2.0/tools/prepare.py --refresh-sources` 更新指纹，再执行 `python -X utf8 docs/开发文档V2.0/tools/build.py` 重建并校验 HTML。工具仅编排文档，不访问数据库或发布服务。

docs 仅保留本版目录及导航入口。编制源文件是本版重建所需输入，按同一 V2.0 基线维护，不作为另一版本发布。文档引用和图形均可离线阅读，外部官方链接仅作进一步查阅。
