## 13. 功能范围说明

本版不包含以下功能：

- 个人知识库。
- 会员、付费权益和商业化功能。
- 社区、关注、点赞、评论、私信、群聊和跨用户协作。
- XP、等级、段位、排行榜、赛季和成长奖励。
- 独立项目管理层级及月、季度、年度计划。
- 课程表导入、会议、预约、外部日历同步和完整日历应用。
- 强制固定时间段、自动生成最优计划、自动复制任务和自动决定任务安排日期。
- 完整四象限计划视图。
- 目标彻底删除、已完成任务恢复为未完成、任务完成质量记录及过去习惯补记。
- 用户自助密码找回、邮箱或手机号绑定、头像和个性签名。
