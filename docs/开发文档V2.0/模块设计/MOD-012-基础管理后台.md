## 一、模块范围

### 1.1 模块职责

受限账户管理与两项站点配置。授权变更持久化且旧权限及时失效；个人成长正文继续隔离。

### 1.2 对应功能清单

| 功能 | 名称 | 本模块承担部分 |
|---|---|---|
| FR-ADMIN-001 | 系统校验后台管理权限 | API-ADMIN-001～009逐次授权 |
| FR-ADMIN-002 | 管理员查看普通用户数量 | API-ADMIN-001 |
| FR-ADMIN-003 | 管理员查询普通用户账户 | API-ADMIN-002、003 |
| FR-ADMIN-004 | 管理员新增普通用户账户 | API-ADMIN-004（USER） |
| FR-ADMIN-005 | 管理员修改普通用户账户 | API-ADMIN-005（USER） |
| FR-ADMIN-006 | 管理员删除普通用户账户 | API-ADMIN-006（USER） |
| FR-ADMIN-007 | 超级管理员查询管理员账户 | API-ADMIN-002、003（ADMIN） |
| FR-ADMIN-008 | 超级管理员新增管理员账户 | API-ADMIN-004（ADMIN） |
| FR-ADMIN-009 | 超级管理员修改管理员账户 | API-ADMIN-005（ADMIN） |
| FR-ADMIN-010 | 超级管理员删除管理员账户 | API-ADMIN-006（ADMIN） |

| FR-ADMIN-013 | 超级管理员修改系统配置 | API-ADMIN-009 |

### 1.3 模块依赖

| 依赖 | 使用原因 | 交互内容 | 失败处理 |
|---|---|---|---|
| 身份、安全账本与审计 | 核对业务资格及形成统一结果 | 由 app 在同一上下文协调业务公开能力 | 依赖不可用按接口错误反馈；核心事务整体回滚 |
| common | 身份、时间、锁、幂等、错误及事件机制 | 明确上下文与固定锁序 | 恢复门禁未开放时拒绝相关写入 |
| PostgreSQL | 持久化与约束 | 本人数据和唯一性/排除约束 | 提交未知则保留原意图核实 |

### FR-ADMIN-001 系统校验后台管理权限

**触发、发起者与前置：**

| 项目 | 说明 |
|---|---|
| 目的与来源 | 查看授权范围人数；FR-ADMIN-001、FR-ADMIN-002、BL-ADMIN-001 |
| 页面入口 | 后台首页人数卡片 |
| 角色与前置 | ADMIN或SUPER_ADMIN有效会话 |

**输入：**采用本章第三部分 API-ADMIN-001 的路径、查询或请求体；身份取服务端会话，不能以客户端归属字段授权。

**事件流：**

1. 服务端从角色确定scopeRoles。
2. 同一只读快照分别统计启用、禁用、逻辑删除。
3. ADMIN的administrators返回null，页面不得将无权限显示为0。

**数据与业务规则：**同动作的字段、版本、日期和唯一性约束见第三部分及其完整对象字典；事务内重读、校验归属及父链。

**异常、取消与执行结果：**参数、权限、版本及状态拒绝不产生部分业务写入；成功以提交后的权威状态为准。需要先独立持久化到期补偿的动作遵循 A07；已提交的前序结束执行不随后续拒绝回滚。请求发送前取消不写入；提交后取消不能撤销已提交事实。各动作特有错误如下节接口定义。

### 4.4 层次职责与调用链

Controller → HTTP DTO 校验/转换 → app 应用用例 → 领域公开能力/Service → 本模块 Mapper/XML → PostgreSQL → 业务结果 → 安全 VO。业务异常在服务层产生，由 app 的全局异常处理映射到 A02 的 HTTP 和业务码；数据库约束冲突只转换为可披露的标准错误，不回传 SQL、内部路径或堆栈。

Controller 不发起独立通知或跨域直接写表；业务模块不引用兄弟模块 Mapper；insights 只读查询允许按固定表契约关联，不取得写所有权。
