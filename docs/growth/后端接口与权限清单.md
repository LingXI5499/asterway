本文件记录核心成长后端接口，所有结果复用 ResultVO，分页复用 PageResultVO。标识符以字符串返回，版本号为数字。请求不得传 userId；身份由认证上下文获取。成长接口只允许普通用户。包含 ADMIN 或 SUPER_ADMIN 的账户一律拒绝，即使同时拥有 USER 基础角色。

## 请求约定

- 创建目标：name 必填；description、completionCriteria、startDate、expectedEndDate 可选，初始 NOT_STARTED。
- 创建阶段：通过目标路径指定父级，name 必填；描述、完成条件、起止日期、sortOrder 可选，初始 NOT_STARTED。
- 创建任务：通过阶段路径指定父级，name 必填；可选描述、完成条件、priority、weight、estimatedMinutes、startDate、dueDate、sortOrder。默认 MEDIUM、权重 1、排序 0，预计耗时未知为 null。
- PATCH 基本资料：必须提交 version，未提交或为 null 的资料字段保持原值；允许描述为空字符串。PUT 完整替换基本资料：必须提交 name/version，可选日期或预计耗时为 null 时清空。父级标识不能通过资料修改接口变更。
- PATCH 状态：status 和 version 必填。任务支持 NOT_STARTED/IN_PROGRESS/PAUSED/COMPLETED；目标与阶段不支持 PAUSED。完成任务自动设置完成时间；重新打开时清空完成时间。
- 归档：version 和 unfinishedHandling 必填，KEEP 为保留安排只读，RETURN_TO_POOL 为结束未完成任务安排。已完成任务保留位置。恢复目标只提交 version，不自动恢复旧安排。
- 删除目标／阶段／任务：查询参数 version 必填。目标须无有效阶段，阶段须无有效任务；任务逻辑删除前结束当前安排。归档目标下禁止普通修改，先恢复再删除。
- 阶段／任务排序：items 数组包含 id、version、sortOrder，1～100 条，同一父资源且 id 不重复；任一失败整体回滚。
- 创建或获取周计划：路径日期必须为周一；同一用户、同一周返回原记录，不重复创建。GET 无记录返回 data=null，不产生写入。
- 创建或获取日计划：日期必须属于本人周计划；过去日期不新建。GET 按日期未创建时返回 data=null。
- 安排任务：weeklyPlanId 必填，dailyPlanId 可空，sortOrder 可选。首次安排 assignmentId/version 同时为空；替换现有安排时两者必须与当前安排一致。目标周不能已结束，目标日不能在过去；从过去安排改期到有效日期允许。
- 相同安排位置：不插入虚假历史；若只调整排序，则更新当前记录和版本。周内改期、跨周改期都先结束旧记录，再插入新记录。
- 移出计划：查询参数 assignmentId/version 必填，结束当前记录并返回任务池，不删除历史。
- 删除周计划：version 必填；存在安排或日计划时 handling=RETURN_TO_POOL 必须明确提供，事务内处理安排和日计划再逻辑删除。包含过去日计划的周不允许普通删除；不删除任务。
- 删除日计划：version 必填；存在安排时 handling=RETURN_TO_POOL 或 KEEP_IN_WEEK 必填。已完成任务不能通过 KEEP_IN_WEEK 重新安排。过去日计划只读。
- 已完成任务禁止新安排或改期；保留原安排以便计划展示。安排历史可查询，包括任务已逻辑删除后的本人历史。

## 查询与返回

- 目标支持 keyword、status、startFrom/startTo、archived、timing、page/size。timing=ALL/CURRENT/FUTURE；默认工作区排除归档和未来目标，显式筛选状态或 archived=true 时默认 ALL。
- 阶段按路径目标分页查询；任务支持 goalId、stageId、status、priority、keyword、assignmentStatus、page/size。POOL 为可安排任务池，只含未完成且未归档任务；WEEK/DAY 由当前安排计算，不在任务表冗余保存。
- 周计划列表支持 dateFrom/dateTo。计划任务、待处理支持目标、阶段、关键字、状态、日期范围及分页；日期参数不替代服务端计算的 today。
- 目标和阶段返回权重进度，空任务返回 null。详情概览最多 100 个子项，完整记录走对应分页接口；不平均阶段百分比。
- TaskVO 返回原始 goalId/goalName/stageName 及当前 assignmentStatus、weeklyPlanId、dailyPlanId。计划任务返回目标、阶段、任务来源和 assignmentVersion。
- 待处理只查询有效当前安排，包含过期日计划和已结束周内的未完成任务，不自动延期、不复制任务、不创建空日计划。
- 归档或删除的祖先不允许继续写入；正常查询不展示已删除祖先下的数据，历史安排查询独立保留。
- 已认证写操作的成功审计与业务同事务写入 Identity 操作日志；失败继续使用公共异常审计。审计不保存请求正文、密码或 JWT。

## 菜单初始化

新增 27 个内置节点：成长规划目录 1 个，目标、阶段、任务、周计划、日计划、待处理页面 6 个，操作按钮 20 个。组件白名单新增 growth/goals、growth/stages、growth/tasks、planning/weekly、planning/daily、planning/pending。

成长前端现已实现，目录及六个主页面入口已启用显示。按钮节点保持隐藏并由动作权限控制；管理身份的菜单返回仍额外排除成长节点。

新库完整授权定义在 identity.sql 标记块内；现有本地库通过 scripts/init_growth_local.ps1 手工提取同一块 SQL，避免复制维护两份授权定义。重复执行不会重复创建记录或覆盖已自定义展示字段，但会补齐 USER 的内置默认授权并启用已完成页面入口；发现扩展或删除记录占用内置编码时整个事务失败。
