## 二、设计与接口契约

### 1. 工具清单

| 工具 | 下游接口 | 权限 | 参数 | 返回要点 |
|---|---|---|---|---|
| `list_goals` | `GET /goals` | `goal:goal:list` | `status`、`keyword`、`archived`、`timing`、`limit(1-20)` | ID、名称、状态、起止日期、进度、total/returned/hasMore |
| `get_goal` | `GET /goals/{goalId}` | `goal:goal:read` | `goalId` | 名称、描述、完成条件、状态、日期、进度、阶段概览 |
| `list_stages` | `GET /goals/{goalId}/stages` | `stage:stage:list` | `goalId`、`status`、`keyword`、`limit(1-20)` | ID、名称、状态、起止日期、进度、total/returned/hasMore |
| `get_stage` | `GET /stages/{stageId}` | `stage:stage:read` | `stageId` | 所属目标、名称、描述、完成条件、状态、进度、任务概览 |
| `get_task` | `GET /tasks/{taskId}` | `task:task:read` | `taskId` | 名称、描述、完成条件、优先级、权重、预计时长、日期、状态、目标/阶段与安排 |
| `list_tasks`（扩展） | `GET /tasks` | `task:task:list` | 新增 `goalId`、`stageId`；保留状态、优先级、关键字、`limit` | 增加任务 ID；统一 total/returned/hasMore |

### 2. 统一规则

- **本人数据**：用户身份只来自服务端认证上下文；目标/阶段/任务的归属由 Java Service 逐次校验，他人资源按 404 返回，不因拥有助手而扩大数据权限。
- **受限动态路径**：`JavaApiClient` 从固定路径白名单扩展为“固定路径 + 受限模板”：`goals/{数字ID}`、`goals/{数字ID}/stages`、`stages/{数字ID}`、`tasks/{数字ID}`；拒绝任意 URL、非数字 ID、路径穿越和查询字符串注入。
- **每页最多 20 条**：所有列表工具有 `limit` 上限 20；返回 `total`、`returned`、`hasMore`、`page=1`，模型被告知第一页不等于全部。
- **列表与详情分离**：目标列表、阶段列表只返回主体字段；目标的阶段概览来自 `get_goal`，阶段的任务概览来自 `get_stage`。这样避免把 Java 列表接口未返回的关联信息说成“0 个”。
- **字段裁剪**：描述/完成条件最多 300 字，超长结果仍受 12 000 字符总上限与截断标记保护；不返回密码、令牌或上游异常原文。
- **时间口径**：目标/阶段/任务日期直接来自 Java；涉及“今天/本周”仍以今日看板 Java 返回值为准。
- **错误区分**：无结果返回 `total=0`；参数不合法、无权限、资源不存在、超时分别转换为模型可读的工具错误；登录失效或管理身份仍终止生成，不伪装成普通查询失败。

## 五、真实验收结果

### 1. 工具确定性验收（20 组，全部通过）

使用真实普通用户令牌与真实 Java 接口逐项核对：

| 场景 | 实际结果 |
|---|---|
| 目标列表 | total、名称顺序与 `/goals` 一致；返回可继续查询的 ID；列表不虚构阶段信息 |
| 目标关键字/分页 | 关键字“四级”仅命中 1 个目标；`limit=1` 时返回 1 条、total=2、hasMore=true |
| 归档目标空结果 | 归档筛选返回 total=0、items=[]，不是错误 |
| 目标详情 | 名称、状态与 `/goals/{id}` 一致；阶段数量与阶段 ID 列表一致 |
| 阶段列表 | total、名称与 `/goals/{id}/stages` 一致；列表不虚构任务数量 |
| 阶段分页 | `limit=1` 时返回 1 条、total=2、hasMore=true |
| 阶段详情 | 名称、所属目标、任务 ID 列表与 `/stages/{id}` 一致 |
| 任务详情 | 名称、优先级、状态、目标名、阶段名与 `/tasks/{id}` 一致，含完成条件 |
| 任务按目标筛选 | total 与 `/tasks?goalId=` 一致，全部属于该目标 |
| 任务按阶段筛选/空阶段 | 有任务阶段 total=2；无任务阶段 total=0 且不是错误 |
| 参数校验 | 非法目标 ID、`limit=21`、字符串 ID、未知工具均返回工具错误 |
| 权限不足 | 上下文缺少目标读取权限时拒绝，不发起 Java 查询 |
| 跨用户隔离 | 用户 B 读取用户 A 的目标/阶段/任务均工具报错且无数据泄露；B 的目标列表 total=0、按 A 目标筛选任务 total=0 |
| 注册表现状 | 7 个工具，参数 Schema 完整，列表 limit 上限 20 |
