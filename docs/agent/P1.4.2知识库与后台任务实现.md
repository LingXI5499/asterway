## 二、关键规则

- 文件只存本地受控目录 `agent/data/knowledge`，库中存 storage_key 与 sha256；同用户未删除同 checksum 直接返回既有文档（不重复写入）。
- 上传仅接受文本/Markdown/PDF/DOCX，单文件 ≤25MB；解析正文上限 200 万字符；PDF/Word 解析组件缺失时任务失败并记录可读错误，不崩溃服务。
- 解析成功：删除旧分块 → 按顺序写入新分块 → 文档 READY → 自动创建 DOCUMENT_EMBEDDING 任务；解析失败：文档 FAILED + 错误信息，任务 FAILED。
- 向量化每次处理一批分块，仍有剩余时再次入队；未配置向量服务时文本检索仍可用（关键词降级），文档保持 READY。
- 后台任务同一引用同一类型只允许一个活动任务（数据库部分唯一索引 + 入队前查询双保险）；文档删除会取消活动任务并逻辑删除。
- 用户范围只取自 Java 验证后的上下文；读权限 `agent:knowledge:read`，上传/删除 `agent:knowledge:manage`。
