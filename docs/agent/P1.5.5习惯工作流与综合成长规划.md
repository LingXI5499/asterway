## 二、综合成长规划语义

1. 用户提出综合规划（如"帮我全面规划下季度成长"）→ COMPREHENSIVE_PLAN；
2. 方案按目标→阶段→任务→周/日计划→安排→习惯的顺序组织，clientKey 引用完整；
3. Java 在单一事务内按依赖顺序创建，任一失败整体回滚；
4. 习惯独立于目标/任务；不把习惯挂到目标下，不自动打卡；
5. 提交结果按类别返回真实 ID，模型与前端只展示名称与结果，不把内部 ID 作为可写参数。
