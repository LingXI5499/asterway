## 二、设计与接口契约

### 1. 工具清单

| 工具 | 下游只读接口 | 权限 | 主要参数 | 返回要点 |
|---|---|---|---|---|
| `list_habits` | `GET /habits` | `habit:habit:list` | `status`（ACTIVE/PAUSED/ENDED）、`keyword`、`categoryId`、`limit(1-20)` | 习惯 ID、名称、状态及中文标签、周期（每天/指定星期）、执行星期、提示时间、分类、开始日期、今日是否已打卡；total/returned/hasMore |
| `get_habit` | `GET /habits/{id}` | `habit:habit:read` | `habitId` | 当前完整规则：名称、描述、完成标准、状态、周期、执行星期、提示时间、分类、开始日期、今日是否打卡、版本 |
| `list_habit_categories` | `GET /habit-categories` | `habit:category:list` | `keyword`、`limit(1-20)` | 分类 ID、名称、排序、版本；total/returned/hasMore |
| `get_today_habits` | `GET /habits/today` + 看板日期 | `habit:habit:list` | `limit(1-20)` | 今天实际应做的习惯、提示时间、是否已打卡、完成/应做数量、页面可操作状态；今天日期与账号时区 |
| `list_habit_checkins` | `GET /habits/{id}/checkins` | `habit:checkin:read` | `habitId`、`dateFrom/dateTo`（同时给或同时省）、`cancelled`、`limit(1-20)` | 业务日期、打卡时间、时区、是否已撤销及撤销时间；已撤销仍保留事实 |
| `list_habit_revisions` | `GET /habits/{id}/revisions` | `habit:habit:history` | `habitId`、`limit(1-20)` | 修订号、动作及中文标签、当时的名称/周期/星期/提示时间/状态快照、生效日期、变更时间；按修订号倒序 |

### 2. 口径与规则

- **习惯独立于目标、任务**：习惯工具只读取独立习惯业务，不通过任务状态推算习惯，也不把习惯说成目标下的任务。
- **今日口径**：今日应做列表、今天日期与账号时区来自 Java 看板与习惯接口；相对日期不以服务器日期或模型推算替代。
- **今日列表范围**：只包含"今天实际应做"的习惯（按周期与开始日期判定，且包含今天已打卡但已被暂停/删除的行）；不在列表里不等于习惯不存在，状态与规则用 `list_habits`/`get_habit` 查询。
- **打卡历史是事实**：`checkedAt` 是原打卡时间；撤销后 `cancelledAt` 有值、仍可读取，不能从列表里"消失"或被当作没打过卡；同一业务日期最多一条有效打卡。
- **规则修订不是打卡**：`list_habit_revisions` 是规则与生命周期快照（创建、编辑规则、暂停、恢复、结束、重新开启、删除、目标归档系统暂停），按修订号倒序；不能用修订时间推算打卡或完成。
- **周期与星期**：周期为"每天"或"指定星期"；`weekdays` 为周一至周日 1～7，工具同时给出中文说明。
- **分页**：每类列表最多 20 条，返回 total/returned/hasMore；超出时只能说明第一页。
- **只读边界**：返回中的 `canCheckin/canCancel` 仅是页面可操作状态，工具不执行打卡或撤销；错误区分参数非法、无权限、资源不存在（含他人资源按 404）与空结果。
