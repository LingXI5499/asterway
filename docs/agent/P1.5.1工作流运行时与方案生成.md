## 二、状态机与规则

```
DRAFT → WAITING_CONFIRM → CONFIRMED → EXECUTING → SUCCEEDED / FAILED
   └→ CANCELLED             └→ CANCELLED           └→ 失败可重试（同一提交键幂等）
任意待确认/已确认超时 → EXPIRED
```

- 方案不可变：修订生成新版本，旧待确认版本标记 SUPERSEDED；确认后写确认令牌哈希（明文只在内部产生，不写日志/不返回浏览器）。
- 同一会话只允许一个活动运行；同一运行只允许一个 CONFIRMED 版本；过期后拒绝确认与提交。
- 幂等提交键 = sha256(runId:planVersionId:snapshotHash)，同一方案版本只产生一条提交记录。
- 方案快照只描述将要创建/安排的内容，不含删除、归档、开始计时或打卡动作；clientKey 仅方案内逻辑引用。
- 上下文中的既有业务事实仍由只读工具实时查询，规划生成不伪造已有实体 ID。
