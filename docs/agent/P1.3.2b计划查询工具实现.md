## 二、设计与接口契约

### 1. 工具清单

| 工具 | 下游只读接口 | 权限 | 主要参数 | 返回要点 |
|---|---|---|---|---|
| `list_weekly_plans` | `GET /weekly-plans` | `planning:weekly:list` | `period`：ALL/CURRENT/PREVIOUS/NEXT；`limit`(1-20) | 周计划 ID、周一/周日日期、total/returned/hasMore |
| `get_weekly_plan` | `GET /weekly-plans/{id}` 或 `/weekly-plans/by-week/{date}` | `planning:weekly:read` | `weeklyPlanId` 或 `period`（二选一） | 周计划详情（周一/周日、版本、创建/更新时间）；无计划返回空并说明 |
| `get_daily_plan` | `GET /daily-plans/{id}` 或 `/weekly-plans/{id}/daily-plans/{date}` | `planning:daily:read`（自动定位周还需 `planning:weekly:read`） | `dailyPlanId` 或日期模式（`planDate` / `relativeDay` TODAY/TOMORROW/YESTERDAY，默认今天） | 日计划 ID、所属周、计划日期；没有周/日计划时返回空并说明 |
| `list_planning_tasks` | `GET /weekly-plans/{id}/tasks` 或 `/daily-plans/{id}/tasks` | 周计划模式 `planning:weekly:read`；日计划模式 `planning:daily:read` | `weeklyPlanId` / `dailyPlanId`（二选一）、`status`、`keyword`、`goalId`、`stageId`、`limit` | 安排 ID、任务 ID/名称、状态、优先级、目标/阶段、周一日期、安排日期、排序 |
| `list_pending_tasks` | `GET /planning/pending-tasks` | `planning:pending:list` | `status`（未完成状态）、`keyword`、`goalId`、`stageId`、`dateFrom/dateTo`、`limit` | 已过原计划日期/所在周已结束但仍未完成的任务及原安排日期 |
| `get_task_assignment` | `GET /tasks/{id}/assignment` | `planning:assignment:read` | `taskId` | 当前安排、所属周/日、周一日期、安排日期；未安排时说明在任务池 |

### 2. “今天/本周”口径

计划类工具不依赖 Python 服务器日期或模型自行推算：

1. 需要相对周/相对日时，工具调用 Java `GET /dashboard/overview`（既有看板接口）读取**账号有效时区的业务日期**；
2. 由该日期计算当周周一（P1.3.2b 内部纯日期运算），再调用 Java 周计划/日计划接口；
3. 结果中返回 `queryWeekStartDate`/`date` 等解析依据，便于核对。

例如“本周计划”会解析为 `dateFrom = dateTo = 本周一`；“上周日计划”会先定位上周一，再按日期查日计划。看板权限缺失时，工具返回可读错误并提示改用明确日期或 ALL 范围。

### 3. 列表与详情分离

- `list_weekly_plans` 只返回定位信息（ID、周一/周日日期），版本与创建时间由 `get_weekly_plan` 返回；
- `list_planning_tasks` 返回计划任务安排，任务本身的描述/完成条件仍用 `get_task`；
- `list_pending_tasks` 只表示“已过原计划日期仍未完成、需要重新安排”的任务，**不等于任务池**；任务池判断用 `get_task_assignment`；
- 列表均返回 `total/returned/hasMore/page`，模型不得把第一页说成全部。

### 5. 已知接口限制（不对外声称）

Java 计划查询 SQL 目前**不按优先级过滤**计划任务/待安排任务（虽然返回优先级字段）。因此 `list_planning_tasks`、`list_pending_tasks` 均不提供“按优先级筛选”参数，避免出现参数无效却被描述成筛选条件的情况；回答中如需优先级只能读取返回字段。
