## 数据与职责边界

- 浏览器 → Java `/asterway/agent/conversations...` → Python `/internal/agent/conversations...` → PostgreSQL `agent` schema / DeepSeek。
- Java 只做 JWT 认证、权限检查、参数校验与代理，不为 Agent 表建立 MyBatis DAO。
- Python 通过 Java `/asterway/me` 复核账户、角色与有效权限；所有 SQL 带 `user_id`；管理身份继续拒绝。
- P1.1 的 `agent:chat:read/send`、P1.2 的六项 `agent:conversation:*` 已加入 `GrowthPermissionConstants`，角色管理接口与 SQL 授权保持一致。

## 接口

统一前缀：公开 `/asterway`，内部 `/internal/agent`。

| 方法 | 路径（省略前缀） | 权限 |
|---|---|---|
| POST | `/agent/conversations` | `agent:conversation:create` |
| GET | `/agent/conversations` | `agent:conversation:list` |
| GET | `/agent/conversations/{id}` | `agent:conversation:read` |
| PATCH | `/agent/conversations/{id}` | `agent:conversation:update` |
| POST | `/agent/conversations/{id}/close` | `agent:conversation:close` |
| DELETE | `/agent/conversations/{id}?version=` | `agent:conversation:delete` |
| GET | `/agent/conversations/{id}/messages` | `agent:conversation:read` |
| GET | `/agent/conversations/{id}/turns/{turnId}` | `agent:conversation:read` |
| POST | `/agent/conversations/{id}/turns/{turnId}/cancel` | `agent:chat:send` |
| POST | `/agent/conversations/{id}/messages` | `agent:chat:send` |
| POST | `/agent/conversations/{id}/messages/stream` | `agent:chat:send` |

SSE 在 P1.1 基础上扩展：`message_start` 增加 conversationId、turnId、requestId、turnVersion；`message_end` 增加同一组标识与最终版本；`error` 增加可空会话与轮次标识。保留 10 秒保活注释。`JwtAuthenticationFilter` 已把 `/asterway/agent/conversations/{id}/messages/stream` 与 P1.1 单轮流式一起绕过 JSON 响应缓存，避免分片被缓存后延迟显示。

幂等与冲突：同一 `requestId` 且哈希一致时，COMPLETED 返回已保存结果；RUNNING 返回 409 与原轮次信息；FAILED、CANCELLED、INCOMPLETE 返回 409 并引导查询轮次；会话或内容不同返回 409。他人或已删除会话 404；版本冲突、关闭后发送、同会话另一轮运行 409。

## 事务与时间

- 所有写入先锁会话行；轮次终态、取消、到期归一使用 `status='RUNNING' AND version=?` 比较更新。
- 开始轮次、用户消息、助手占位在同一短事务提交，随后释放锁再调用模型。
- 生成中按 `AGENT_PARTIAL_SAVE_INTERVAL_SECONDS` 分批保存；最终正文、轮次终态提交成功后才发送 `message_end`。
- 约束相关时间统一使用数据库 `now()`，避免 Python 与数据库时钟偏差触发 `created_at/updated_at` 检查。
- 摘要只在完整结束（`stop`）后作为后台任务运行；按会话版本与原覆盖边界比较更新，失败不覆盖旧摘要。
