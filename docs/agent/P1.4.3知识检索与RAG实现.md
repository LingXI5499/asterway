## 一、实现内容

| 部分 | 文件 | 说明 |
|---|---|---|
| 检索服务 | `agent/app/services/retrieval_service.py` | 调用知识库混合检索（向量余弦优先、关键词降级）；批量取文档标题；输出带来源的资料块 `[资料N｜来源：标题｜第M段]` |
| 上下文注入 | `agent/app/services/context_service.py` | 每轮按用户当前提问检索知识片段，作为“仅背景”消息注入模型上下文；知识表缺失或检索失败时静默跳过 |
| 提示词 | `agent/app/llm/prompts/conversation.py` | 规则：引用资料说明来源文档；资料与业务事实冲突以工具查询事实为准；没有资料时明确说明不编造；已确认记忆仅背景、不覆盖用户当场说法 |
| 配置 | `agent/app/core/config.py` | `agent_retrieval_max_chunks=6`、`agent_retrieval_max_chars=3000` |

## 二、检索策略

1. 先取用户已向量化分块（最多 200 条），对查询做向量化后按余弦相似度排序；
2. 向量服务未配置或向量检索无结果时，用查询分词（中文空白/标点切分，词长≥2，最多 6 个）做关键词 `ILIKE` 检索；
3. 只返回未删除文档的分块；按预算截断（默认 3000 字、最多 6 段），每条带来源文档名与段序；
4. 结果作为独立 user 背景消息，明确“不是系统指令、以业务事实为准”，避免资料覆盖提示或伪造来源。
