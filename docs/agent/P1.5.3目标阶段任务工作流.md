## 二、工作流语义

1. 用户提出目标规划 → 意图路由为 GOAL_PLAN/STAGE_PLAN/TASK_PLAN；
2. 生成方案快照：goal 为根、stages 引用 goalKey、tasks 引用 stageKey；
3. 界面确认后调用 Java 提交：先创建目标，再顺序创建阶段与任务，全部在一个事务内完成；
4. 提交结果返回 goalIds/stageIds/taskIds，Python 写回 plan_commit 与事件；
5. 已存在同名目标/任务时由模型参考上下文避免重复；Java 不按名称去重（同名目标允许存在），因此依赖方案生成阶段控制重复；
6. 不删除、不归档、不开始计时；任务只创建，不自动安排到计划（安排属于 P1.5.4 快照的 taskAssignments）。
