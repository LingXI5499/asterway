## 二、状态机与规则

- 候选（CANDIDATE）→ 确认（CONFIRMED）/ 拒绝（REJECTED）；已确认 → 归档（ARCHIVED）；任意未删除状态可逻辑删除。
- 只有已确认记忆参与跨会话上下文；候选、拒绝、归档、删除记忆不注入。
- 内容按用户内幂等：创建候选时同内容已有候选/已确认记录直接返回既有记录；确认时若已有同内容已确认记录返回冲突。
- 所有写操作要求 `version` 乐观锁；读接口要求 `agent:memory:read`，写接口要求 `agent:memory:manage`；用户范围只取自 Java 验证后的上下文。
- 状态时间与更新时间使用“当前时间与行创建时间的较大值”，避免时钟回拨违反数据库时间约束。
- 记忆表缺失时上下文注入静默跳过并记录警告，不影响会话；不会因为记忆模块异常导致对话失败。
