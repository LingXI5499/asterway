## 二、工具契约

| 工具 | 参数 | 返回要点 |
|---|---|---|
| `get_statistics_summary` | `period`（TOTAL/WEEK/MONTH/YEAR/RANGE，默认 MONTH）、`anchorDate`、`dateFrom/dateTo`（仅 RANGE）、`goalId/stageId/taskId` | 周期与日期区间、时区；执行累计/区间秒数与分钟、会话数；习惯完成/应做/完成率；目标/阶段/任务完成动作、去重完成任务数、归档/恢复动作 |
| `get_statistics_trends` | 同上 + `limit(1-20)` | 逐日：日期、实际秒数、会话数、习惯完成/应做/完成率、各类完成动作、归档/恢复；total/returned/hasMore |
| `get_growth_timeline` | 同上 + `limit(1-20)` | 事件类型与中文标签、对象名称、发生时间；目标/阶段/任务/习惯/执行/计划事件，按发生时间倒序 |
| `get_habit_statistics` | 同上 + `groupBy`（HABIT/CATEGORY）+ `limit(1-20)` | 习惯总计与分组（名称、已删除标记、完成/应做/完成率），不受目标筛选影响 |
| `get_object_statistics` | `period`、`anchorDate`、`dateFrom/dateTo`、`goalId/stageId/taskId` | 当前有效未归档目标/阶段/任务按状态的数量快照 |

口径：
- 统计周期边界与"今天"由 Java 账号时区解析，工具不自行推算；RANGE 必须同时给起止日期，其他周期不接受日期参数。
- `total*` 为账号全部历史累计，`range*` 为所选统计周期；回答必须说明口径。
- 习惯统计独立于目标/阶段/任务筛选；对象状态分布是当前快照，不代表历史完成动作。
- 时间线只展示真实事实（状态变更、打卡/撤销、执行开始/结束、安排事件），不按当前状态反推过去。
- 完成率为实际完成/应做，分母为零时为空，不做假 100% 或 0%。
