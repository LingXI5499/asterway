## 2026-11-05 追加调整

根据用户对会话页面和回复格式的反馈，做以下调整：

1. **移除“关闭会话”入口**。原 P1.2 后端把 CLOSED 设计为只读归档状态；用户要求像 DeepSeek 网页版一样，只保留新建、切换、重命名、删除、提问与回答。页面不再展示关闭操作、状态筛选和已关闭标签，删除是移除会话的唯一入口。后端关闭接口保留但不再被页面调用。
2. **本地开发库清理**：把唯一一条非删除的 CLOSED 会话改回 ACTIVE（版本号加一、清空关闭时间），使历史会话可以继续提问；当前库中已没有非删除的 CLOSED 会话。
3. **助手回复改为 Markdown 渲染**：标题、段落、有序/无序列表、加粗/斜体、引用、代码块、行内代码、分隔线、链接、图片和表格都可以正常显示；表格可横向滚动，链接新窗口打开并带 `noopener noreferrer nofollow`。
4. **修复“回复未完成”误报**：Java 公开消息 VO 的字段名是 `complete`，页面此前误读为 `isComplete`，导致所有历史助手消息都被判定为未完成。改为读取 `complete` 后，完成态不再显示“回复未完成”警告；真正被停止、取消、失败或截断的消息仍会提示。

## 页面范围

沿用 `/agent` 单页，不新增路由，替换 P1.1 的单轮临时对话界面：

- 桌面端两栏：左侧会话列表，右侧当前会话消息区；两栏等高，内部各自滚动。
- 移动端（宽度小于 900px）：会话列表变为左侧滑出面板，由右侧标题栏的列表按钮打开，遮罩点击收起。
- 页面顶部标题与面包屑继续由 `WorkspaceView` 统一渲染，本页只负责会话与消息。

## 交互

1. **新建会话**：点击“新建”调用 `POST /agent/conversations`，插入列表顶部并打开；首次发送后若标题仍为“新对话”，用问题前 24 字自动改名（重命名失败不阻断提问）。
2. **切换会话**：点击列表项加载详情与最新消息；生成中禁止切换，避免中断当前回复。
3. **搜索**：标题回车搜索后重新加载第一页；不做输入即请求。
4. **加载更多**：列表分页每次 30 条，按服务端 `total` 判断是否还有下一页；失败回退页码，重试不会跳页。
5. **重命名**：弹窗校验非空且不超过 100 字，携带当前 `version`，409 时回读详情刷新版本。
6. **删除会话**：二次确认后逻辑删除并移出列表；若删除的是当前会话则回到空态，历史事实仍保留在数据库。
7. **历史分页**：打开会话取最新 24 条；上翻到顶部 120px 或点击“加载更早的消息”按 `beforeMessageNo` 续页，前插后保持阅读位置不跳动。
8. **发送与流式**：本地先插入提问与助手占位，再以 `requestId`（浏览器 UUID）发起 SSE；`message_start` 记录轮次标识与版本，`delta` 追加正文，`message_end` 写入完成状态、结束原因与用量。
9. **Markdown 展示**：助手正文按 Markdown 渲染，支持标题、列表、表格、加粗、代码块、引用、链接和图片；用户提问保持纯文本；渲染不启用原始 HTML，避免模型输出注入页面结构。
10. **停止生成**：浏览器中止连接并调用轮次取消接口；已收到的正文保留为“已停止生成”，可再次提问。
11. **刷新恢复**：详情返回 `runningTurn` 时每 2 秒查询轮次，结束（完成/失败/取消/截断）后回读最新消息并同步会话版本；提示条可停止该轮。
12. **失败与未完成**：网络或接口错误显示可公开错误文案与追踪号；已持久化的未完成回复保留部分正文，并提供“再次提问”。
13. **权限**：无发送、列表、创建、改名、删除权限时隐藏或禁用对应操作，最终仍由服务端逐接口校验。
14. **登录态变化**：令牌会话标识变化时清空列表、消息、草稿与恢复轮询，重新加载；卸载页面时中止流式连接并尽力取消当前轮次。

## 数据链路

```
浏览器（Vue 状态）
  → frontend/src/api/agent.js
  → Java /asterway/agent/conversations...
  → Python /internal/agent/conversations...
  → agent schema 三表 / DeepSeek
```

- 列表与详情使用服务端返回的 `version`；改名、删除都带版本，冲突由服务端返回 409，页面回读详情后重试。
- 发送流程：`POST /{id}/messages/stream` → `message_start(turnId, turnVersion)` → `delta` → `message_end(turnVersion, finishReason, usage)`；结束后回读详情同步会话版本，并回读最新一页消息，把本地占位替换为数据库记录。
- 打开流程：`GET /{id}` 与 `GET /{id}/messages?size=24` 并行；`runningTurn` 存在时启动轮询。
- 停止流程：中止 fetch → `POST /{id}/turns/{turnId}/cancel {version}`；卸载页面时同样尽力取消。
- 请求标识：每次发送由浏览器生成 UUID，服务端据此做幂等与重放判定。
- 完成态：公开消息 VO 的 `complete` 由 Python 的 `is_complete` 映射；页面只读 `complete`，不再读取内部字段名。
