## 轮次链路

```
用户提问
  → 组装系统提示、摘要、最近消息和当前提问
  → 流式调用模型（带 tools）
  → 模型返回 tool_calls
  → 保存助手工具请求，预留结果序号和下一条助手占位
  → 校验工具名、参数和当前用户权限
  → 调用 Java 只读接口（单工具 8 秒）
  → 保存并回填 tool 结果消息
  → 模型继续生成（最多 3 个工具轮、6 次工具调用）
  → 最终回答流式输出
  → 提交轮次终态并保存助手正文
```

- 工具轮不提交终态；只有最终回答轮结束才写入 `COMPLETED` / `INCOMPLETE`。
- 超过工具轮数或次数后，下一轮使用 `tool_choice=none`，要求模型基于已有结果作答；关闭工具功能时不发送工具定义。
- 普通查询失败、超时、业务权限不足或参数无效生成工具错误结果；登录失效、管理身份和发送权限失效会中止本轮生成。
- 工具请求和结果使用现有消息表的工具列保存，不增加表。完成轮次的后续上下文重建完整请求／结果链；取消或失败轮次只带入用户提问。公开聊天分页继续只返回用户提问与最终回复。
- 普通响应与 SSE 共用生成流程。工具状态条仍是实时提示，不新增历史工具审计页面。

## 配置

| 配置 | 默认值 | 作用 |
|---|---|---|
| `AGENT_TOOLS_ENABLED` | `true` | 关闭后模型只使用对话上下文，不携带工具。 |
| `AGENT_TOOL_MAX_ROUNDS` | `3` | 最多工具轮数。 |
| `AGENT_TOOL_MAX_CALLS` | `6` | 最多工具调用次数。 |
| `AGENT_TOOL_TIMEOUT_SECONDS` | `8` | 单次工具执行超时。 |
| `AGENT_TOOL_MAX_RESULT_CHARS` | `12000` | 单个工具结果写入模型前的长度上限。 |
