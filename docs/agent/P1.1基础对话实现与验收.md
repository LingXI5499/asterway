## 接口与事件

浏览器只访问 Java，公开接口无版本号：

| 方法 | 路径 | 请求 | 结果 |
|---|---|---|---|
| POST | `/asterway/agent/chat` | `{message}`，1～8000 字 | `ResultVO<AgentChatResultVO>`，含 reply、model、finishReason |
| POST | `/asterway/agent/chat/stream` | 同上 | `text/event-stream` |

Python 内部对应 `/internal/agent/chat`、`/internal/agent/chat/stream`。两者同时校验内部调用密钥和用户 Bearer JWT，再通过 Java `/asterway/me` 确认用户、角色、权限及账户状态。旧 `/api/v1/chat` 兼容入口同样受认证保护，不再作为公开浏览器接口。

SSE 事件：

| 事件 | 内容与含义 |
|---|---|
| `message_start` | traceId、model；开始接收，不表示回复成功 |
| `delta` | text；追加纯文本，前端不执行 HTML |
| `message_end` | model、finishReason、complete、usage、traceId；只有 stop 且 complete=true 才显示完成 |
| `error` | code、message、status、traceId；终止本次回复，不自动重发 |

等待期间每 10 秒发送 SSE 注释保活，不按保活包延长登录会话。EOF 缺少结束事件时，前端显示回复未完成。主动停止会取消浏览器请求，Java 在写出失败时关闭 Python 响应流，Python 取消生产任务并关闭模型流；不承诺取消前已产生的模型用量归零。

浏览器断开属于预期取消，Java 在流式回调中收敛写出异常，不再交给 JSON 全局异常处理器，避免二次写出及误报 500。

## 本地启动与配置

本轮服务端口：前端 5175、Java 8089、Python 8001。访问 `http://127.0.0.1:5175/agent`，使用已有普通用户登录。

1. Java 仍按根目录 README 的私密工作目录方式启动；公开 `application.yml` 的数据库、JWT 和内部调用密钥为空。
2. Python 在 `agent/` 使用 Python 3.12，安装 `pyproject.toml` 中既有依赖；将 `.env.example` 复制为被忽略的 `.env`，填写模型密钥、Java 本地地址及内部调用密钥。
3. Java 私密 YAML 的 `asterway.agent.internal-key` 与 Python 的 `AGENT_INTERNAL_KEY` 一致。密钥使用 32～128 位字母、数字、下划线或短横线，不能提交真实值。
4. 从 `agent/` 启动 `python -m uvicorn app.main:app --host 127.0.0.1 --port 8001`；本地开发可添加 `--reload`。不要将内部 Python 服务直接开放公网。
5. 前端执行 `npm run dev`。页面请求经 Vite 代理到 Java，浏览器不接触内部密钥或模型密钥。

Java → Python 固定使用 HTTP/1.1，适配当前 Uvicorn；SSE 的分片和停止能力已在这条链路实测。现有 JWT 的 JSON 响应缓存对该流式路径绕过，避免等整段生成完才显示。默认连接超时 5 秒、Java 请求上限 150 秒、Python 总请求上限 120 秒、模型调用超时 60 秒。

## 权限与数据库边界

`app/src/main/resources/sql/agent.sql` 本阶段只登记 `agent:chat:read`、`agent:chat:send`、成长助手页面及发送按钮。默认禁用隐藏，仅授予 USER。无新增数据库表。

`scripts/initialize_agent_local.ps1 -ValidateOnly` 在随机隔离 schema 中验证准备态、普通用户授权、管理身份误授权移除及重复执行不推进版本，最后整段回滚。构建完成后执行不带参数的脚本，才手工启用本地已实现入口；脚本固定开发库，不改原有业务事实。新库先完成 Identity 初始化，已有库可单独执行 Agent 授权标记块。应用不自动执行 SQL。

P1.2 会话、消息和摘要 SQL **尚未编写或部署**；未新增 SQLAlchemy、LangGraph、pgvector 或 RabbitMQ 依赖。当前模型只接收系统提示和本次提问，不读取或修改任何成长业务数据。P1.3 之前不开放业务工具。
