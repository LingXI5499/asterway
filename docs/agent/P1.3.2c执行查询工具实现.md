## 二、设计与接口契约

### 1. 工具清单

| 工具 | 下游只读接口 | 权限 | 主要参数 | 返回要点 |
|---|---|---|---|---|
| `get_current_execution` | `GET /executions/current` | `execution:session:read` | 无 | 当前任务、开始时间、累计实际秒数、当前时间段、心跳截止；无执行时返回空并说明 |
| `list_executions` | `GET /executions` | `execution:session:list` | `status`、`taskId`、`goalId`、`stageId`、`period`（ALL/TODAY/YESTERDAY/THIS_WEEK/LAST_WEEK/CUSTOM）、`dateFrom/dateTo`、`limit(1-20)` | 任务、状态、开始/结束时间、总实际秒数；带日期时同时返回区间秒数；total/returned/hasMore |
| `get_execution` | `GET /executions/{id}` | `execution:session:read` | `executionId` | 执行详情（含累计/区间秒数、当前时间段）+ 首屏时间段（最多 20 段，含 hasMore） |
| `list_execution_segments` | `GET /executions/{id}/segments` | `execution:session:read` | `executionId`、`limit(1-20)` | 每段开始/结束、服务端有效截止时间、实际秒数、结束原因中文说明、时区、是否未结束 |
| `get_execution_summary` | `GET /executions/summary` | `execution:session:read` | `scope`（TASK/STAGE/GOAL，可空）、`scopeId`、`period`（TODAY/YESTERDAY/THIS_WEEK/LAST_WEEK/CUSTOM）、`dateFrom/dateTo` | 累计与区间实际秒数（同时给分钟换算）、会话总数/区间数、已结束/进行中/已暂停数、最近执行时间 |

### 2. 口径与规则

- **执行事实优先**：耗时、暂停、结束原因全部读取执行计时事实；不使用任务当前状态倒推历史完成情况或历史耗时。工具本身不写任何执行数据。
- **今天/本周口径**：相对日期区间通过 Java `GET /dashboard/overview` 读取账号有效时区的业务日期后计算（与 P1.3.2b 一致），不使用服务器日期或模型自行推算。
- **累计与区间分开**：`get_execution_summary` 返回的 `totalActualSeconds/totalSessions/finishedSessions/runningSessions/pausedSessions` 是限定范围（任务/阶段/目标或全部）内的**全部历史累计**；`rangeActualSeconds/rangeSessions` 是所选日期区间内数值。回答时必须说明口径。
- **会话数与时间段数不混用**：`totalSessions` 是执行会话数，`list_execution_segments.total` 才是时间段数；Java 的汇总数值不被二次加工。
- **暂停历史**：时间段返回 `endReason` 及中文说明（用户暂停、心跳超时自动暂停、到计划边界暂停、登录失效自动暂停、用户结束、任务删除结束、目标归档结束）；未结束段 `open=true`，实际秒数按服务端有效截止时间计算。
- **分页**：列表与时间段每页最多 20 条，返回 total/returned/hasMore；执行详情只带首屏时间段，超出提示用 `list_execution_segments`。
- **错误区分**：空结果为正常返回；非法参数、无权限、资源不存在（含他人资源按 404）转换为模型可读工具错误；登录失效继续终止生成。
