# 合作伙伴演示 · 约 3 分钟

演示前：在“设置与数据”重置演示数据，然后返回“今日总览”。无需注册。

## 0:00–0:30 看见产品

介绍：“星行纪把长期目标变成今天的行动。如果计划有变化，成长伙伴可以提供一份先预览、再确认的调整方案。”

首页展示三件重要的事、真实行动清单、习惯、成长档案。点击一项任务完成，让对方看到任务数和 XP 同步变化。

## 0:30–1:15 建一个自己的目标

进入“我的目标”，创建“30 天完成个人项目”。空目标显示“待规划”。在详情添加一个里程碑“第一版演示”，再添加一个今天的行动“整理产品演示资料”。

返回今日完成这个行动，再打开目标详情，查看关联进度。这里要确认：合作伙伴是否理解目标、里程碑和任务的关系。

## 1:15–1:40 形成习惯和日程

进入“习惯追踪”，完成今天的阅读打卡。展示周矩阵和补打范围。切换“计划日程”，查看今日/明日任务与待安排任务池。

## 1:40–2:20 计划可以调整

打开“成长伙伴”，点击“帮我调整”（默认今天剩余 40 分钟）。说明这是本地规则演示。右侧查看保留、延后的任务和旧/新日期。

先取消一次，证明没有改变数据；再生成并“确认应用”，查看日程变化。回伙伴页“撤销最近一次方案”，恢复原计划。

也可以选择一个目标点击“拆解”，展示新增行动的草案。

## 2:20–3:00 看到成长、讨论需求

进入“成长复盘”，看最近 7 天真实记录，写一句本周反思并保存。刷新页面，展示任务、打卡与复盘仍在。

最后打开设置，介绍可以导出备份或清空开始。

收集三条反馈：

- 哪一步最有价值，哪一步最难理解？
- 如果明天真的使用，最缺少什么？
- 当前应先保留、删除、调整哪些功能？

不要把真实 AI、云同步或账号服务介绍为已完成能力。本版用来确立需求，随后按反馈修改。
