# 合作伙伴演示 · 约 5 分钟

演示前可在设置导出备份，再重置演示数据。无需注册。明确说明：当前是前端原型，AI、社区用户和消息都是本地演示。

## 0:00–1:00 目标和行动

打开今日总览，完成一项任务，看看 XP 和成长进度。进入目标，新建“30 天完成个人项目”，添加阶段和两个任务。回到今日执行其中一个，说明“一个目标下可以有多个任务”。

## 1:00–1:45 从模板起步

打开成长模板，搜索“雅思”或“Vue”。预览后调整开始日期与计划天数，点击加入目标。展示新目标下的阶段与多个任务、配套习惯；任务分布在计划周期内。

## 1:45–2:45 伙伴独立操作与个人知识

打开成长伙伴，输入“记住：我每天有 20 分钟学习”，预览并确认保存。

再输入“帮我制定 30 天日语学习计划”，查看目标、行动与习惯的整套预览以及记忆引用，确认批量创建。到知识库看到刚才保存的偏好。

可演示勾选“新增自动执行”，再输入“添加习惯「每天写一句复盘」”；直接建立后撤销最近一次创建。说明未来将接真实 AI，本版用规则展示工作流程。

## 2:45–3:45 社区与同行者

进入成长社区：图文瀑布流 → 打开内容 → 点赞、评论、收藏 → 收入知识库。打开计划分享，预览并加入自己的目标。

切到视频，打开一段实际可播放的原创演示动画，用上一段/下一段切换。点击分享成长，发布一段自己的文字。本机刷新后仍能看到。

## 3:45–4:20 社群与消息

打开成长社群，加入“下班后的成长时间”，进入群聊。发送“今天完成一个小行动”，展示自己消息和明确标注的模拟回复。也可从示例用户主页发起私信。

## 4:20–5:00 积分、身份与反馈

在习惯页面打卡，进入今日行动赛报名并领取奖励（示例已完成今天的一项任务）。看看自己的积分、段位、徽章。进入会员页只切换演示身份，不收费。

最后展示成长复盘与完整数据导出。让合作伙伴指出：哪些流程愿意使用、哪些页面太重、下一轮最需要修改什么。

原型讨论重点是需求与使用路径。登录、联网、真实 AI、支付和数据库留到原型认可后实施。
