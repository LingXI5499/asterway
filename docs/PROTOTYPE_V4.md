## 新计划对应不同方法

效率计划的原按钮只添加普通待办。这轮新增三步流程：选择方法 → 设置行动 → 预览并确认。六种方法产生不同的数据和执行入口：

| 方法 | 创建行为 |
| --- | --- |
| 四象限 | 每项行动分别选择重要/紧急组合；进入四象限继续整理 |
| 每日三件事 | 每份计划最多三项重点，按填写顺序检查预算、缓冲和留白，再建立时段 |
| 时间分块 | 设置开始时间与可用分钟，按顺序绕开已有固定时段；装不下时要求调整 |
| 番茄专注 | 选择 15/25/45/50 分钟，创建任务后进入关联专注空间；已有计时不被强制重置 |
| 先做关键难事 | 第一项作为重要、较高精力的关键行动和当天重点，其余作为配套下一步 |
| GTD 收集与下一步 | 建立目标与行动，行动不指定日期，进入待安排任务池 |

每份方法计划仍是一个目标下的多个任务，方法标签可导出并在刷新后保留。效率页显示「我的方法计划」，目标卡片也显示方法；继续支持最近一次批量创建的保护性撤销。新建不修改既有日程或既有重点；每日三件事页可以进一步统一收敛当天重点。

## 以图文和视频分享成长

推荐流混合图文、计划与视频；图文频道只显示图文笔记；视频频道只显示视频。内容仍以自律、学习和成长过程为主题。

- 默认图文封面采用四张原创 SVG 学习日记插画，视频采用原有三段实际可播放的原创动画。
- 图文可上传最多六张本地图片，发布前预览，详情中可逐张切换；每篇上传媒体总大小小于 1 MB。
- PC 详情左侧图片/视频、右侧作者与正文、互动和评论；手机采用全屏阅读，上方媒体、下方讨论。
- 视频沉浸播放支持实际自动静音播放、循环、原生播放器控制；PC 可用按钮或 ↑/↓ 切换，手机可在媒体区域上下滑切换。
- 原有点赞、评论、收藏、知识收集、计划复制、发布、社群和本地消息保留。

## Aster 是全局伙伴

所有产品页面提供右下角入口与 Ctrl/Cmd + J 快捷键。PC 为右侧面板，手机为全屏面板。快捷面板与完整助手工作台使用同一个 Pinia 会话状态，关闭、换页或打开完整工作台后可继续对话；对话记录仍保存在原有个人数据中。

当前可演示：新建目标、任务与习惯；模板制定计划；按四象限安排当天；保存个人情况；引用原始知识与记忆做回顾；按实际任务/习惯记录复盘；解释当前页面；添加每日站内提醒；确认操作与撤销。

每日提醒先产生草案，确认后保存并开启站内提醒，可暂停、删除，随完整备份导出。仅应用打开时到点显示，每日不重复；「每日轻提醒」总开关控制是否显示。同一分钟多个事项合并提示。没有后台系统通知、实时网络数据或真实大模型推理。

这是全局助手的交互原型，并不代表已具备回答所有问题的真实 AI。后续按认可的原型接入模型、权限、知识检索、工具调用、提醒服务与用户体系。
