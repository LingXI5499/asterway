本轮按已批准的八页、七类弹窗／抽屉和七十三项交互完成编码，保留原账户十五页及成长九页，共三十二个页面。沿用现有 Vue、Vue Router、Element Plus、ECharts 和依赖锁文件，没有重建原前端或升级技术版本。

页面位于 frontend/src/views 下的 dashboard、execution、habit、notification、statistics；公共组件位于 components/personal。七类弹窗／抽屉是执行详情、习惯编辑、打卡历史、规则历史、分类编辑、消息处理、三类主体共用状态历史。时间段不增加独立增删改查界面。

接口依据为 Execution 十四个操作和后续三十八个操作，共五十二个后端契约。界面实际对接五十一个 HTTP 操作：习惯编辑统一使用 PUT 完整更新，同一业务的 PATCH 兼容接口不另做表单或重复调用。不开放客户端补录日期或改耗时。habit-actions.js 处理今日行缺少主体版本、撤销需要打卡版本的差异。原计划列表的 version 属于安排，开始执行会重新读取任务本身的版本，不覆盖安排版本。

## 状态、权限和数据口径

- 普通用户的个人业务必须同时满足 USER 身份、没有管理身份、具备动作权限。路由、菜单、按钮和全局轮询使用同一规则；管理员即使同时保留 USER 也不会开放个人业务。后端继续承担最终鉴权和所属人校验。
- 计时数据由共享 stores/personal.js 持有，路由切换和侧栏折叠不销毁计时。显示从服务端实际秒数平滑增加，并封顶到心跳或安排截止；暂停间隔不累计，离线后不补写客户端时间。
- 当前控制端每二十秒发送心跳，其他登录端只读取当前会话；暂停、结束都携带版本，结束二次确认。失败后只重新读取结果，不盲目重发写命令。心跳／自动读取沿用后端不续期规则。
- 退出、换登录 SID、强制改密码或权限身份变化会清除前端计时和消息状态；请求代号、取消信号与会话检查阻止迟到响应覆盖新账户或新筛选。403 停止相应后台重复请求，导航重新读取账户能力。
- 习惯按每日一次有效打卡展示。今天已完成后变更规则、暂停、结束或删除，仍读取后端保留的完成事实；删除或封存后的行不开放撤销入口，不开放过去补卡。规则历史显示原始快照。
- 站内消息的已读和目标处理独立，打开详情不自动伪造已读。确认带消息及目标版本，409 读取最新状态；失效来源保留历史且不开放确认。
- 统计读取真实执行段、打卡与状态事件，习惯总计为总完成数除以总应做数，无分母显示“无应做”。来源筛选只限制成长／执行／安排，习惯仍为账户口径。图表和明细均按当前日期页展示，不截取前一百条伪装全部历史。
- 远程来源及分类选择按页继续加载。筛选输入与已提交查询分开，异步切换不会混用不同区间的概览、图表和分页结果。

## 后端读取与导航兼容

只补齐本轮界面直接需要的兼容内容，没有改变数据表或技术版本：

1. MenuServiceImpl 加入 habit/index、habit/categories、notification/index、dashboard/index、statistics/index 组件键，保留原 execution/index。
2. 看板任务增加可选 section=TODAY／WEEK_UNDATED，经 DTO、Service、Mapper/XML 在分页前筛选；不传参数仍兼容原列表。防止在已分页混合列表上做前端过滤而产生空页和错误总数。
3. 页面显示检查发现无执行段的日期被计为整日耗时。StatisticsMapper 的日期 LEFT JOIN 产生空行后，LEAST/GREATEST 忽略 NULL 导致整日裁剪；现对不存在的执行段明确取零。没有改写事实、增加持久化字段或在图表层覆盖数据。
4. 工作区空路径重定向补齐独立路由名，消除父命名路由的空子节点警告；页面数量不计重定向或菜单别名。

## 菜单手工启用

已执行 scripts/enable_remaining_frontend_local.ps1，核对 identity.sql 与已验收 SQL 哈希后，只执行 EXECUTION AUTHORIZATION 和 REMAINING AUTHORIZATION 两段，事务内设置后端、前端就绪标记。脚本固定本地开发库，不包含 DDL、历史初始化或数据清理，不随应用启动执行。

实际结果：六个新页面菜单启用并可见，USER 获得六项入口，Execution 与后续模块共三十项动作权限启用，管理角色个人业务直接授权为零，旧目标删除权限保持停用。执行记录和成长时间线从主页面进入，没有另增菜单。新库或其他开发库仍按文档顺序手工初始化 SQL，再在前端构建启动后执行该启用脚本。
