# 后续模块后端实现与启动说明

本文保留后端阶段交付时的范围和验证记录。后续八页前端及必要的后端读取兼容修正已经完成，当前菜单状态与最新构建证据见 [前端实现与验收说明](前端实现与验收说明.md)，下文“前端未修改／菜单隐藏”描述的是后端交付时点。

本次完成 habit、notification、dashboard、statistics 四个后端模块，以及 goal／stage／task 状态历史、Execution 和账户的配套联动。前端未修改。源码仍为 12 个 Maven 子模块，各业务只依赖 common；app 仍只有唯一启动类、本地 application.yml 和十份业务 SQL。

## 当前交付

- habit：四张表的 Entity、Mapper/XML、DTO/VO，分类与习惯各保留一条完整 Service 接口／实现／Controller 主链；修订和打卡作为习惯从属事实。
- notification：消息主链和精确目标达标条件、轮次、消息同步提交；确认完成交给 Goal 主链，不增加跨业务 Maven 依赖。
- dashboard：读取当前计划、习惯、目标和执行事实；没有看板持久化表。
- statistics：总／周／月／年／自定义周期，投入汇总、逐日趋势、真实时间线、习惯分组和当前对象概况；没有统计持久化表。
- goal／stage／task：各自历史 Entity、Mapper/XML、VO 和原 Service 中的追加／读取，新增三个只读历史入口。
- common：个人身份过滤、日历快照和中立联动接口；Identity 的权限白名单和菜单过滤已覆盖新四个模块。

新增 38 个接口的字段、权限和状态处理见 [后端业务与接口约定](后端业务与接口约定.md)。原 SQL 第一阶段结果继续保留在 [SQL 阶段记录](SQL阶段验收说明.md)；本次真实构建与启动证据见 [backend-build-results.json](backend-build-results.json)。

## 构建和启动

Maven／IDEA 使用 JDK 17，保留原 Spring Boot、MyBatis、PostgreSQL 和 Redis 版本。根目录执行：

```powershell
mvn -B -ntp -f backend/pom.xml '-Dmaven.test.skip=true' clean package
java -jar backend/app/target/app-0.1.0-SNAPSHOT.jar
```

当前本机后端端口为 8089。启动时校验数据库和 Redis 连接，配置仍只使用 app 的 application.yml；未增加环境变量、profile、配置导入或 SQL 自动执行。已有应用占用端口时先关闭对应本地实例，不结束其他项目进程。

OpenAPI [接口元数据](http://localhost:8089/v3/api-docs) 与 [阅读界面](http://localhost:8089/swagger-ui/index.html) 可直接查看。接口元数据的读取只核对注册情况，不调用具体业务，不代表业务联调通过。

## 本地手工初始化

已手工执行 scripts/init_remaining_local.ps1，按已验收源 SQL 的哈希核对后，补齐八张新表和目标条件列。现有阶段、任务、周日计划、安排、执行会话及执行段在同一事务内比较行数和内容校验值，保持不变。旧状态基线与可信完成导入按 SQL 设计处理，未清理任何旧安排。

本机开发库现为 26 张业务表，新增 23 项普通用户后端权限已启用；新页面入口可见数为 0。账户、原成长、Execution 原有授权保持。应用角色对追加历史及规则修订仅有 SELECT／INSERT，不开放 UPDATE／DELETE／TRUNCATE。

该脚本只供手工使用，不随应用启动执行，不包含默认账号密码或 Flyway 迁移链。它只接受本机开发库，遇到部分新表或不兼容列定义会拒绝，不删除表或旧业务数据。重复初始化不重建已有完整八表，状态基线、可信完成和通知保持幂等。
