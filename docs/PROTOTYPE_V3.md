# v0.3 · 有方法地成长

这轮围绕「目标 → 下一步行动 → 判断轻重缓急 → 留出时间 → 专注 → 复盘」完善原型。Vue 纯前端实现，保留旧数据与已有社区功能，暂不引入后端和复杂存储。

## 效率计划

- **四象限**：重要/紧急独立判断。桌面 2×2 看板，每个象限内部滚动；手机单列。拖动卡片或下拉选择可改变判断，原排期保持不变。支持搜索、目标筛选、今日/待安排范围、编辑、完成与进入专注。
- **每日三件事**：自动建议或手选最多三项。设置日期、开始时间、可用分钟、缓冲、留白与精力。生成草案后展示每项开始/结束时间、选择原因和跳过原因；确认后同步日程与当天重点。
- **时间分块**：同一排程流程，最多六项。已安排在未来的任务不提前挪动，未选任务及装不下的任务保持原排期；绕开已有固定时段，不缩短任务、不跨午夜。草案生成后相关任务被修改或新增占位时，确认会拒绝陈旧草案，要求重新生成。
- **方法指南**：四象限、每日三件事、时间分块、番茄专注、先做关键难事、收集与下一步。提供适用情境、实际操作入口与方法来源。
- **可撤销**：最近一次排程可在效率计划或成长伙伴撤销，保留之后发生的用户修改。排程不改变任务奖励。

默认重要性来自优先级（中/高），紧急性来自截止日期（不超过参考日期两天，包括逾期）。安排日期表示打算哪天做，截止日期表示最晚哪天完成。两者分开，不将所有今日任务都判为紧急。手动标注可以覆盖默认判断，属于产品原型规则，可在需求讨论中调整。

## 专注空间

选择任务或自由专注，提供 15/25/45/50 分钟专注与 5/10 分钟休息。可以暂停和恢复，关闭弹窗、切换页面、刷新后按真实时间恢复；页面外显示可返回的计时状态。

用户主动记录已执行的完整分钟，每段只记录一次；到时不自动记账，休息不累计专注。完成任务与记录专注分别操作。右侧显示真实记录形成的当天统计、最近七天趋势与任务上下文。

进行中计时单独保存于浏览器，未完成计时不进入导出备份；导入或重置成长数据会清掉当前计时，已记录的专注仍属于成长数据。

## 与原有页面的连接

- 今日总览显示当天工作量和效率入口，重点排序参考轻重缓急与精力。
- 日程可进入时间分块，确认草案后定位对应日期所在周。
- 任务编辑增加折叠的截止日期、重要性、紧急性、精力字段，普通添加仍保持轻量。
- 成长伙伴能理解「按四象限帮我安排今天 120 分钟的三件事」；使用同一套本地规则，始终预览并确认改期，开启新增自动执行也不绕过确认。
- 全局搜索支持方法、知识和模板，直接进入对应内容；任务/目标继续可直接编辑。
- 修复原任务/目标编辑错误访问习惯频率导致的报错。
