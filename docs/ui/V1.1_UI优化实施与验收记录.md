# Asterway V1.1 UI 优化实施与验收记录

日期：2026-11-05。本轮仅改进已有前端展示与交互，启动现有前后端供用户验收。Agent 已由用户明确暂停，不增加工程、表、接口或菜单。

## 实施基线与边界

保留现有 Vue、Vue Router、Element Plus、ECharts、Vite 版本，保留 32 个路由页面及其业务操作。界面使用靛蓝、雾白与青绿的统一语义色、系统中文字体、轻边框和一致圆角。Light / Dark / System 偏好仅保存在浏览器，不增加后端配置。

附件中的阶段 PAUSED、任务完成后不可重开与已验收业务规则不同，保持当前三状态阶段和任务可重开的行为，不为视觉设计改变业务。计划任务沿用原安排身份和分页事实，不能将当前页样本标作整周全量。缺少接口数据的指标不虚构、不发起逐行补齐请求。

## 样式与组件盘点

- 原 style.css：认证、外壳、卡片、表单、表格、成长详情和计划样式。
- 原 personal.css：执行、习惯、通知、统计、响应式和悬浮条。
- 两份原样式先迁移为 CSS Token，保留原类名；tokens/themes/element-overrides/global 分别承载基础常量、主题、组件库覆盖和统一布局，避免删除仍被业务使用的规则。
- 现有 GrowthActions、GrowthEditor、TaskAssignmentDialog、OrderDialog、HabitEditor、ExecutionDetails、NotificationDetails 等保留原交互与 API；新增 UI 组件承担图标、主题、页头、状态与空状态。
- Lucide Vue 官方已将 lucide-vue-next 改名为 @lucide/vue，采用维护中的包名，按需引入图标，不引入另一套 UI 框架。依据：[Lucide Version 1](https://lucide.dev/guide/version-1)。

## 验收边界

本轮不建立单元、系统、集成或 E2E 测试框架。浏览器检查仅使用真实接口和现有数据，不造业务数据，不自动执行归档、删除、重置密码等写入流程。完整业务验收由用户操作；未执行项保持“待验收”，不写为通过。
