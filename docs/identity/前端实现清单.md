# 账户前端实现清单

本轮实现 15 个页面：登录、注册、强制改密、个人中心、我的设备、用户管理、角色管理、权限管理、菜单管理、在线会话、登录日志、操作日志、账户设置、403、404。

- 个人中心包含资料、密码和时区标签页，支持取消待生效的时区修改。
- 用户管理包含筛选、分页、新增、编辑、启停、删除、密码重置、角色分配和 ECharts 统计。
- 角色提供展示资料修改、权限授权、菜单授权；USER 与 SUPER_ADMIN 的内置核心授权受保护。
- 权限和菜单使用独立表单，内置编码只读，内置记录禁止删除。菜单支持目录、页面和按钮。
- 设备支持当前、指定、全部退出；后台会话支持强制退出。
- 日志只读，提供用户 ID 筛选、分页、详情。
- 账户设置管理站点名称和注册开关。
- 公共组件包含可折叠多级导航、面包屑、分页、弹窗、详情抽屉、确认框。

接口统一使用 `/asterway` 前缀和 ResultVO。修改携带服务端 version。JWT 接受响应头续签，处理退出后的迟到响应与标签页同步。权限与菜单来自 `/me`，后端执行最终权限及数据范围校验。

本轮检查为生产构建、开发服务启动及登录页 HTML 可达性。未运行账户业务流程、单元测试、系统测试、集成测试。接口业务行为待后续安排验收。

开发服务在 5175 端口启动；本地后端在 8089 端口启动，PostgreSQL 和 Redis 就绪。通过前端代理请求公开账户配置返回 HTTP 200、code=OK。该检查仅确认服务连接，不代表账户业务验收。
