# Identity 接口与权限清单

2026-11-04：以下后端接口已编码并完成编译与启动检查，尚未执行接口业务测试。统一结果类为 common.result.ResultVO，分页结果为 PageResultVO。

## 通用契约

- 所有业务接口使用 `/asterway`，不保留 `/api/v1`。
- JSON 请求与响应；统一响应预定为 `code`、`message`、`data`、`traceId`，HTTP 状态不统一伪装成 200。
- ID 返回字符串，时间使用 ISO 8601。分页参数 `page` 从 1 开始、`size` 默认 20、最大 100；列表为 `items`、`total`、`page`、`size`。
- 乐观锁修改携带 `version`，并发冲突返回 409；唯一用户名冲突也返回 409。
- 未认证 401，权限不足 403，字段错误 400，资源不存在 404，限流 429，数据库或 Redis 不可用 503。
- 管理员请求高权限账户标识时不返回目标资料；用户列表、详情、数量、会话及日志都使用同一管理范围规则。
- 只有身份已经有效且有对应权限时才进入业务；本人资料和设备标识均取已验证身份，不能接受客户端指定归属。

## 公开入口

| 方法与路径 | 输入或查询 | 结果及规则 |
|---|---|---|
| GET /asterway/public/account-settings | 无 | 仅站点名称、注册是否开放，不泄露后台配置元数据 |
| GET /asterway/time-zones | keyword、page、size | 可用 IANA 时区，用于识别失败后的手动选择 |
| POST /asterway/captchas | scene 为 LOGIN/REGISTER | 创建短时挑战，不能返回正确位置 |
| POST /asterway/captcha-verifications | challengeId、offset、客户端挑战随机标识 | 一次性场景绑定验证凭据，不能跨登录/注册复用 |
| POST /asterway/registrations | username、password、confirmPassword、captchaTicket、clientNonce | 创建 USER 账户及基础角色，成功后引导登录，不自动登录；拒绝任何角色输入 |
| POST /asterway/sessions | username、password、captchaTicket | 201，返回 JWT、会话标识、到期时间；设备描述仅作展示 |

注册与登录校验密码长度 8～50，不限制字符组合，不自动裁剪密码。用户名 1～30，英文字母大小写无关唯一。注册不填写昵称和时区；昵称初始使用用户名，时区初始使用 UTC，登录后在个人中心完善。验证码失败不增加凭据失败计数；用户名不存在与密码错误统一提示。连续五次凭据错误锁定五分钟。

## 本人账户与设备

| 方法与路径 | 权限 | 关键输入或效果 |
|---|---|---|
| GET /asterway/me | identity:profile:read | 安全资料、角色编码、当前权限、授权菜单；不返回密码哈希 |
| PATCH /asterway/me | identity:profile:update | username、nickname、version |
| PUT /asterway/me/password | identity:password:update | currentPassword、newPassword、confirmPassword、version；成功撤销全部旧会话 |
| GET /asterway/me/time-zone | identity:timezone:read | 当前与待生效时区、生效时刻 |
| PUT /asterway/me/time-zone | identity:timezone:update | timeZone、version；按旧时区次日午夜生效，无需业务定时任务也可在访问时应用到期状态 |
| GET /asterway/me/sessions | identity:device:list | 当前有效登录设备；标记 current，会话列表查询不承担后台保活 |
| DELETE /asterway/me/sessions/current | 身份有效 | 当前退出；撤销后不再续签 |
| DELETE /asterway/me/sessions/{id} | identity:device:revoke | 只能撤销本人会话 |
| DELETE /asterway/me/sessions | identity:device:revoke | 退出全部设备 |

必须修改初始密码时，仅开放完成改密所需的本人资料、改密及退出接口，不允许直接进入管理功能。

## 后台用户管理

| 方法与路径 | 权限 | 关键输入或效果 |
|---|---|---|
| GET /asterway/user-statistics | identity:user:count | 普通、管理、禁用及删除等统计，按操作者范围返回 |
| GET /asterway/users | identity:user:list | keyword、enabled、role、page、size；默认排除已删除 |
| GET /asterway/users/{id} | identity:user:read | 安全资料和允许范围的角色信息 |
| POST /asterway/users | identity:user:create | username、nickname、initialPassword、confirmPassword、timeZone；先建立 USER，管理身份通过独立角色接口分配 |
| PATCH /asterway/users/{id} | identity:user:update | username、nickname、version，不混入改密或角色字段 |
| DELETE /asterway/users/{id} | identity:user:delete | version；逻辑删除、停用、递增安全版本、撤销会话 |
| PATCH /asterway/users/{id}/status | identity:user:status | enabled、version；停用使旧会话失效 |
| PUT /asterway/users/{id}/password | identity:user:reset_password | newPassword、confirmPassword、version；强制下次改密并撤销全部会话，不返回旧密码 |
| GET /asterway/users/{id}/roles | identity:user:assign_role + 超管 | 返回当前角色，用于授权回显 |
| PUT /asterway/users/{id}/roles | identity:user:assign_role + 超管 | roleIds、version；保留 USER，仅允许调整 ADMIN，不允许通过接口增删 SUPER_ADMIN |

管理员只能操作没有 ADMIN/SUPER_ADMIN 关联的账户；超管也不能通过这些接口删除、停用或降权至没有可用超管。全部相关操作使用统一锁顺序保护，不将前端隐藏按钮当作限制。

## 角色、权限、菜单与配置

这些接口必须同时满足动作权限与超级管理员身份。本轮角色只查询、调整展示资料和授权，不开放自定义角色创建删除。

| 资源与方法 | 权限 |
|---|---|
| GET /asterway/roles | identity:role:list |
| GET /asterway/roles/{id} | identity:role:read |
| PATCH /asterway/roles/{id}，仅名称、说明、version | identity:role:update |
| GET /asterway/roles/{id}/permissions | identity:role:read |
| PUT /asterway/roles/{id}/permissions，permissionIds、version | identity:role:grant_permission |
| GET /asterway/roles/{id}/menus | identity:role:read |
| PUT /asterway/roles/{id}/menus，menuIds、version | identity:role:grant_menu |
| GET/POST /asterway/permissions | identity:permission:list / create |
| GET/PATCH/DELETE /asterway/permissions/{id} | identity:permission:read / update / delete |
| GET /asterway/menus、GET /asterway/menus/tree | identity:menu:list |
| POST /asterway/menus | identity:menu:create |
| GET/PATCH/DELETE /asterway/menus/{id} | identity:menu:read / update / delete |
| GET /asterway/settings/account | identity:setting:read |
| PUT /asterway/settings/account | identity:setting:update |

授权采用集合替换，校验去重、引用、对象状态后原子保存；改变角色授权时递增角色 version。内置编码不可改，内置角色和关键权限菜单不可删除；扩展权限或菜单删除前必须没有引用，目录删除前不得有有效子节点。菜单路径与组件键使用白名单规则。

账户配置只接收 siteName、registrationEnabled 及两项配置对应的版本，不接收任意配置键。公开注册在真正写入用户前再次读取注册状态。

## 会话与审计

| 方法与路径 | 权限与范围 |
|---|---|
| GET /asterway/sessions | identity:session:list；仅管理范围内账户的有效会话 |
| DELETE /asterway/sessions/{id} | identity:session:revoke；不能通过会话标识绕过目标范围 |
| GET /asterway/login-logs | identity:login_log:list；管理员仅看已识别普通用户的记录，匿名失败记录仅超管可见 |
| GET /asterway/operation-logs | identity:operation_log:list；普通管理员仅看本人操作且目标为普通用户的记录；授权和系统配置审计仅超管可见 |

## 已编码的会话设计

- Spring Security + Bearer JWT + Redis；不启用 Servlet/Spring Session JDBC 双会话认证。
- 多端独立会话；连续七天无有效操作过期，没有额外的固定七天总寿命。
- JWT 与 Redis 同步滑动续期，响应头 X-Session-Token 返回新令牌，前端只接受同一会话较新的续签结果。
- 自动轮询、设备列表查询不用于延长会话；退出请求不续签。退出后的迟到响应不得恢复登录。
- Redis 原子校验续期不得重新创建被撤销的会话；数据库当前状态和 auth_version 仍需验证。
- 权限使用数据库最新有效角色与权限，不把 JWT 中的旧权限作为最终授权依据。
- 设备描述不是永久指纹；同一设备再次登录也会创建独立会话。

上述规则已编码，仍需后续经用户安排进行接口及浏览器业务验收。本轮按要求没有进行测试体系建设或业务测试。

验证码创建和验证、注册、登录均需 clientNonce，长度16～128；验证码校验票据名称为 captchaTicket。统一结果 data 中承载业务 VO，创建资源使用 HTTP 201，删除或退出成功仍返回 ResultVO，data 为空。
