## 接口清单

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | /api/v1/public/bootstrap | 站点名称与注册开关 |
| GET | /api/v1/public/time-zones | IANA 时区筛选与签名游标分页 |
| GET | /api/v1/auth/csrf | 当前会话 CSRF 请求头名称与令牌 |
| POST | /api/v1/auth/captcha-challenges | 创建 REGISTER 或 LOGIN 拼图 |
| POST | /api/v1/auth/captcha-challenges/{challengeId}/verify | 服务端验证原图位移 |
| POST | /api/v1/auth/register | 创建普通账户、初始时区和账户控制行 |
| POST | /api/v1/auth/login | 校验凭据并轮换会话与 CSRF |
| GET | /api/v1/auth/me | 本人资料、时区、日期与会话快照 |
| PATCH | /api/v1/auth/profile | 乐观版本控制下修改用户名或昵称 |
| POST | /api/v1/auth/password/change | 校验原密码、修改密码并撤销全部旧会话 |
| POST | /api/v1/auth/logout | 检查未结束执行后退出当前会话 |
| PUT | /api/v1/auth/device-time-zone | 登记设备时区变更 |
| GET | /api/v1/operations/{idempotencyKey} | 登录后核实本人原账户操作结果 |

所有写请求带 `X-CSRF-TOKEN` 与标准 UUID `Idempotency-Key`。
更新请求使用十进制字符串 `expectedVersion`；密码变更和退出还要求 `confirmed=true`。
请求体拒绝未知字段，不允许通过请求体指定用户 ID、权限或安全版本。

## 已实现业务规则

- 用户名仅允许英文字母、数字和汉字，大小写不影响唯一性和登录，展示保留原形式。
- 字符串按 Unicode 码点校验，不 trim、不截断；新密码长度为 8～50，不增加强度门槛。
- 注册昵称省略时使用本次用户名，后续改名不联动昵称；注册成功后须手动登录。
- 拼图由服务端生成并判断，挑战有效期 120 秒、每次挑战只有一次有效猜测，验证材料加密保存。
- 拼图绑定匿名作用域、用途与消费意图；滑动错误不增加密码失败次数。
- 规范化提交名累计 5 次有效凭据错误后锁定 5 分钟；成功或锁定到期清零。
- 认证 principalName 使用稳定账户 UUID；每次恢复身份核对账户可用性与凭据、安全版本。
- 用户名或昵称同值保存不增加版本；版本冲突返回当前版本，不自动覆盖其他页面的修改。
- 改名保留已有会话；改密要求原密码正确、新旧不同，并使所有旧会话失效。
- 改密和正常退出均检查 RUNNING、PAUSED 执行；当前没有执行表时不存在可持久化的未结束执行。
- 时区变更在原业务日结束后生效；再次换目标保留原边界，改回当前时区可取消待生效项。
- 到期时区在账户读取前补偿，也由账户维护调度处理；历史时区区间不重排。
- 同一操作标识校验受密钥保护的参数指纹；响应丢失时使用原键核实，不盲目发起新操作。
- 认证去重结果不包含 Cookie 或 CSRF，不能从缓存结果重新签发登录会话。
- 退出意图绑定原会话，迟到的旧退出请求不能直接注销新登录的另一账户。

## 2026-10-26 服务职责整理

保留 `AccountApi` 作为账户模块对 app 的公开 Java 能力接口，不为每个内部服务新增接口和实现类。
`service` 目录仅保留以 `Service` 结尾的业务服务，辅助组件按实际职责放入对应目录。

| 位置或类 | 职责 |
|---|---|
| service/AccountService | 实现 AccountApi，分派模块公开调用 |
| service/AccountProfileService | 读取本人资料、修改用户名与昵称 |
| service/AccountPasswordService | 原密码校验、修改密码与撤销旧会话 |
| service/AccountLogoutService | 检查退出条件并删除当前会话 |
| service/AccountAccessService | 账户锁、可用性、会话版本及未结束执行条件检查 |
| service/AccountIdempotencyService | 原 AccountOperationService，处理幂等执行、重放与结果查询 |
| service/AccountPublicQueryService | 原 AccountPublicService，查询站点初始化信息与时区列表 |
| assembler/AccountSnapshotAssembler | 组装已读取的账户与时区，不执行数据库查询 |
| validation/AccountValidator | 字段、版本、密码确认与时区参数校验 |
| captcha/CaptchaImageFactory | 生成拼图图片、缺口与挑战材料 |
| infrastructure/transaction/AccountTransactionExecutor | 封装原有短事务传播规则 |
| infrastructure/security/AccountKeyStore | 稳定密钥文件与私有目录管理 |
| infrastructure/security/AccountCryptography | 摘要、挑战材料加解密 |
| infrastructure/security/SecureTokenGenerator | 安全随机数与令牌生成 |
| infrastructure/security/AccountSecurityLedger | 独立安全账本的核验与提交确认 |
| infrastructure/serialization/AccountJsonCodec | JSON 持久化材料编解码 |

移除原 `AccountStateSupport`：规则检查归 AccountAccessService，快照组装归 AccountSnapshotAssembler，
待变更状态由 AccountState 的显式方法构造。时区区间创建归 ZonePeriod，注册服务不再为创建区间依赖时区业务服务。
原 `AccountSecretService` 拆分为密钥存储、加解密、随机材料生成和 JSON 编解码组件。
既有密钥文件名、账本 JSON 字段及签名输入顺序、用途前缀和密文布局沿用原实现。

调用路径按职责区分：

- 单模块调用：Controller → AccountApi → AccountService → 对应内部业务 Service → Mapper。
- 需要会话协调：Controller → AccountUseCase → AccountApi，同时由用例协调 Spring Security 会话与 CSRF。

这里的 API 是进程内 Java 接口，不是模块间 HTTP 请求。
内部 Service 由 AccountService 或其他内部服务调用，不需要逐个面向 Controller 开放。
AccountUseCase 只用于有实际协调职责的流程：登录建立身份与会话、改密后清理当前会话、退出后清理安全上下文等。
注册、修改资料、时区同步及公开查询现有路径不强制经过 AccountUseCase。

本次未修改 HTTP 契约和数据库迁移，未启动或重启服务；仅完成后端全模块编译，未编译或运行测试。

该目录应独立于数据库备份保存；更换或丢失密钥不能直接生成替代密钥绕过安全核验。

账户安全变更先保存受保护意图，再提交数据库事实，最后确认账本结果。
账本只保存受密钥保护的摘要，日志和审计不保存密码、哈希、Cookie 或验证令牌。

## 启动方式

在仓库根目录打包后端，跳过测试：

```powershell
mvn -B -f backend/pom.xml -pl app -am '-Dmaven.test.skip=true' package
```

从 `backend` 目录启动后端：

```powershell
java -jar app/target/app-0.1.0-SNAPSHOT.jar
```

从 `frontend` 目录启动页面：

```powershell
npm ci
npm run dev -- --host 127.0.0.1 --strictPort
```

访问页面：`http://127.0.0.1:5173/`。
本地 Swagger：`http://127.0.0.1:8088/swagger-ui/index.html`。
非 local 环境默认关闭 Swagger，Cookie 的 Secure 属性默认启用；本地 HTTP 环境单独关闭 Secure。
