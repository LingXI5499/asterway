## 设计范围

| 项目 | 数量 |
|---|---|
| 功能模块 / 现行FR | 12 / 132 |
| HTTP接口 / 数据表 | 95 / 36 |
| 页面 / 系统处理 | 20 / 7 |
| 开发批次 / 综合验证 | 19 / 72 |

后端统一采用 JDK 17、Maven 3.9.4、Spring Boot 3.5.16、MyBatis XML 和远程 PostgreSQL 17.11；服务器已有 pgvector 0.8.7，MVP 不启用向量业务。前端采用 Vue 3.5.44 + TypeScript 6.0.3 + Vite 8.3.4，构建环境为 Node.js 24.22.0 LTS + npm 11.19.1。完整版本与锁定方式以 [12 技术版本基线](12-技术版本基线与环境核验.md)为准。

系统保持一个后端应用，所有项目表与框架表均无物理外键。模块、实现顺序与技术边界以00、06及技术依据为准。
