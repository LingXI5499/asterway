## 状态与维护

后端骨架位于 `backend/`，默认分支为 `main`。Maven 工程模型已核验；业务实现、数据库迁移、接口联调、前端及部署恢复仍须按手册实施与验收。文档完整不代表软件运行通过。

`编制源文件/` 保存本版重建输入，`tools/` 保存正文编排和渲染规则，`data/` 保存目录、指纹与校验结果。调整输入并复核后，在仓库根目录执行：

```powershell
python -X utf8 docs/开发文档V2.0/tools/prepare.py --refresh-sources
python -X utf8 docs/开发文档V2.0/tools/build.py
```

校验器会检查单一版本目录、输入指纹、文件链接、需求覆盖、模块映射、接口字段、示例和离线页面。检查通过后同步提交正文、数据和 HTML。发布分支、提交和合并标题使用 `LIngXI` 前缀。
