## 处理过的问题与限制

- 新导航改成分组后，原直接子元素选择器失效，导致链接挤在一起；已修正选择器，使用逐行 flex 布局与内部滚动。
- 新页面补齐独立布局样式，社区采用瀑布流、消息采用分栏、模板采用卡片、榜单采用排名列表。
- 格式配置改用分号，避免 Vue 多语句事件被格式化为不可编译表达式；格式化后的代码再次构建与完整浏览器验证通过。
- 浏览器测试中两项断言最初与实际标签/1280 响应列数不符，已按产品布局修正并完整复测。
- v0.3 修复任务/目标编辑读取缺失习惯频率的报错；全局搜索后的模板关键词筛选实际生效。旧 Vite 进程缓存缺失新增 CSS 引入，已重启本项目进程并通过浏览器 computed style 与截图核实。
- v0.3 浏览器测试的计时浮层、知识标题和撤销按钮定位最初与实际标签不一致，已修正定位并完成回归。
- v0.4 视觉检查发现阅读插画的英文 `&` 未转义，导致封面无法显示；已修正 SVG XML，并增加全部图文封面真实加载断言。四张插画均通过 XML 解析。
- 提醒确认时同步开启站内提醒开关，避免新建提醒后因原有默认关闭而不显示；仍支持在设置中统一关闭。全局面板与页面弹窗使用独立标题 ID。
- 视频为三段原创 6 秒动画，无外部媒体资源；可实际播放，不代表已接入真实短视频平台。
- 没有真实后端、账号、云同步、网络社区、开放 AI 或支付；没有做十万用户并发测试。
- 使用 Edge 模拟小屏，未验证真实 iOS/Android、Safari、屏幕阅读器或移动触控视频滑动手势。
- 本地媒体容量有限，原型上传单文件小于 1 MB；生产媒体上传与存储留待服务端阶段。
