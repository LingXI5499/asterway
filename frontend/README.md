# Asterway 前端工作区

Vue 3、Vue Router、Element Plus 和 ECharts。使用现有 `/asterway` REST 接口及 `ResultVO`，本地代理转发至后端 8089 端口。

## 本地运行

运行 `npm install`、`npm run dev`。本地固定使用 5175 端口；端口占用时直接提示，避免自动顺延后与后端允许来源不一致。构建使用 `npm run build`。

## 功能范围

保留 15 个账户路由页面和 9 个成长路由页面，新增 8 个后续业务页面，共 32 页。账户页面包括登录、注册、强制修改密码、个人中心、我的设备、用户管理、角色管理、权限管理、菜单管理、在线会话、登录日志、操作日志、账户设置、403 和 404。

- 个人中心包括资料、密码和 IANA 时区设置，显示延迟生效时间，允许取消待生效修改。
- 用户管理包含筛选、分页、新增、修改、逻辑删除、启停、密码重置和角色分配。
- 角色保留 USER、ADMIN、SUPER_ADMIN，提供权限与菜单的集合授权，核心内置授权受保护。
- 权限和菜单提供维护表单，菜单支持目录、页面、按钮，组件键采用后端白名单。
- ECharts 使用用户统计接口，展示账户构成和账户状态。禁用账户是未删除账户的子集，图表按实际口径计算。
- 日志只读，设备和会话支持退出，退出当前或全部设备后返回登录。
- 菜单和操作按钮根据权限显示，后端执行实际权限及数据范围校验。

## 会话与并发

Bearer JWT 保存在当前浏览器本地存储中，权限和菜单由 `/me` 读取。接受响应头返回的较新续签，退出后的迟到响应不会恢复会话。401 清理会话并跳转登录。修改携带服务端 version，409 展示服务端原因，重新加载记录后可再次编辑。

## 验证边界

本轮进行构建、开发服务启动和页面资源可达检查，不建立或执行单元测试、系统测试、集成测试。业务行为仍需后续安排实际账户验收。

## 核心成长工作区

新增 9 个路由页面：目标管理/详情、阶段管理/详情、任务中心/详情、周计划、日计划、待处理。复用资料表单、状态和归档对话框、任务安排、安排历史、任务池选择与排序弹窗。进度直接使用后端结果，空集合不虚构百分比。

普通用户有看板权限时默认进入今日看板，否则按权限进入目标管理或个人资料；管理员与超级管理员只进入管理功能，后端也拒绝其成长请求。管理员即使同时保留 USER 基础角色也不例外。后台仍保留个人资料、密码和设备安全入口。

成长组件键、菜单路由及权限树已接入，目录和六个页面入口可见，按钮节点不作为侧栏菜单展示。管理员通过角色管理配置 USER 的成长权限，不向管理角色分配成长能力。

详细页面、交互、约束与验证边界见 docs/growth/前端实现与验收说明.md。本轮只构建与启动检查，未执行真实账户业务验收。

## 执行、习惯、通知和历史

本轮新增今日看板、执行工作台、执行记录、习惯管理、习惯分类、站内消息、历史统计、成长时间线八页，按已批准范围完成 73 项交互和七类弹窗／抽屉。

- 计时始终使用服务端实际耗时与截止，心跳绑定当前登录端；支持多个暂停会话、连续执行时间线、跨页计时条，不加入客户端补时。
- 习惯支持个人分类、每天／指定星期、今日打卡与撤销、暂停／恢复／结束／重新开启、打卡和规则历史，历史完成率不由当前规则倒推。
- 消息已读与目标确认分开，处理携带消息及目标版本；失效消息保留历史。
- 看板按今日和本周未定日分别分页；统计支持总／周／月／年／自定义、三个 ECharts 图表、习惯及分类分组、真实时间线。
- 原目标、阶段、任务详情接入实际耗时和状态历史，任务与计划列表接入执行；计划行开始时重新读取任务版本。
- 轮询和菜单折叠不重建业务页面，退出或登录身份变化会清除计时状态，迟到响应不会回写新账户。

新侧栏页面使用已验收 identity.sql 授权块手工启用，入口脚本为 scripts/enable_remaining_frontend_local.ps1，不随应用启动执行。执行记录从工作台进入，时间线从统计进入，不额外创建菜单节点。

实现、验证边界及业务人工验收入口见 [后续前端说明](../docs/remaining/前端实现与验收说明.md)。本地构建／启动和页面显示检查已记录，完整业务流程仍为 NOT_VERIFIED；未建立严格测试体系。
