# Asterway 前端

Vue 账户页面：注册、登录、账户中心，包含服务端拼图、资料编辑、密码修改、退出及设备时区同步。
使用服务端会话与 CSRF；操作结果不确定时保留原意图，敏感输入只放在页面内存中。

2026-10-27 接入 Element Plus 2.14.7，按实际使用注册组件并统一为简体中文、蓝白亮色界面。
登录及注册使用组件表单、提示、滑条和远程时区选择，账户中心按资料、安全、时区分区。
业务请求、校验与原操作标识重试机制沿用现有实现；本次仅完成构建和页面显示检查，未运行测试。

```powershell
npm ci
npm run dev -- --host 127.0.0.1 --strictPort
```
