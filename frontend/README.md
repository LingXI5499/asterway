# Asterway 前端

Vue 账户页面：注册、登录、账户中心，包含服务端拼图、资料编辑、密码修改、退出及设备时区同步。
使用服务端会话与 CSRF；操作结果不确定时保留原意图，敏感输入只放在页面内存中。

```powershell
npm ci
npm run dev -- --host 127.0.0.1 --strictPort
npm run build
```

开发服务器端口为 5173，`/api` 代理到 `http://127.0.0.1:8088`。
前后端使用同一个主机名访问，以保证会话和 CSRF Cookie 正常传递。
