# Asterway 前端

Vue 3、Vue Router、Element Plus、ECharts 与 Vite。所有业务请求通过 `/asterway` 访问 Java，由后端完成身份、权限、版本和数据归属校验。

## 运行与验证

`npm ci` 安装锁定依赖；`npm run dev` 启动开发服务；`npm run build` 生成生产资源；`npm run test:agent` 验证方案及复盘交互。

## 工作区

- 保留账户管理、目标／阶段／任务、周／日计划、执行计时、习惯、通知、看板与历史统计。
- 全局成长助手入口保持可达；单页整合连续对话、资料与记录，以及右侧方案、复盘和实际进度。
- 左侧导航和右侧方案面板可拖动、键盘调宽并恢复宽度；窄屏使用抽屉展示。
- 流式回复支持停止、重试、复制和历史恢复，显示实际处理步骤。
- 用户显式接受方案后才提交创建或更新安排；迟到的旧会话响应不能覆盖当前会话，失败不能报告为成功。

生产部署由反向代理转发 `/asterway`。内部通信密钥及模型密钥不发送给浏览器。详见 [V2.0 发布说明](../docs/releases/V2.0.md)。
